## Dépendances croisées et cycles évités

Les attributions du tableau empêchent toute référence de `GWGUI.MediaEngine` vers les nouvelles bibliothèques. Les compositions physiques restent dans le moteur. Les volumes, systèmes de fichiers, migrations et normalisations associées passent dans `GWGUI.MediaFileSystems`. Les résultats qui agrègent représentation physique, volumes et métadonnées passent dans `GWGUI.MediaAnalysis`.

- `Decoding`, `Formats`, `Recognition` et `Reconstruction` restent dans le moteur et remplacent les imports de systèmes de fichiers par des primitives physiques du moteur.
- `Conversion/Fat12`, `Conversion/Migration`, `Exploration/Interpretation`, `Exploration/Partitioning` et `Exploration/Sequential` passent dans systèmes de fichiers.
- Les contrats, documents, métadonnées, résultats et services intégrés de `Exploration` passent dans analyse.
- `ScpCaptureInfo` et `ScpCaptureInfoReader` restent dans le moteur.
- `PhysicalSectorTreeBuilder` passe dans analyse et doit produire une projection physique, jamais de faux fichiers.
