# Habillages d’écran

Les habillages d’écran sont une idée future. Aucun travail de code, d’image, de configuration, de
test ou de traduction ne doit commencer sans décision explicite.

L’idée consiste à proposer, en plein écran, un cadre décoratif autour de l’image émulée : télévision
ou moniteur pour une machine de salon, corps de la console pour une machine portable. Le plein écran
classique doit rester disponible sans habillage.

Une machine pourrait proposer plusieurs variantes correspondant à ses modèles ou couleurs. Pour une
console portable, le cadre peut être recadré, mais l’écran doit rester entier, correctement placé et
sans déformation. Une première réalisation resterait décorative; les boutons, voyants et autres
animations éventuelles appartiennent à une évolution ultérieure.

Avant d’ouvrir une nouvelle feuille de tâches, il faudra décider :

- si les habillages sont aussi disponibles en mode fenêtré;
- quelles machines et variantes font partie du premier ensemble;
- si les images sont créées, recherchées ou fournies par les modules;
- leurs règles de redistribution et de transparence;
- le comportement lorsque l’image attendue manque.
