# Documents archivés

Les fichiers de ce dossier sont conservés pour leur valeur historique. Ils ne décrivent plus nécessairement l’état actuel ni l’ordre des prochains travaux.

Un document a été archivé ici lorsqu’il mélangeait trop d’anciennes étapes, de résultats datés et de tâches désormais remplacées pour être corrigé proprement sans perdre son historique.

La documentation actuelle commence dans [l’index principal](../README.md).
