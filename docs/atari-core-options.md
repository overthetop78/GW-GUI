## Visibility rules and source anomalies

- Hatari, Atari800, Stella 2023, ProSystem and Beetle Lynx do not call `RETRO_ENVIRONMENT_SET_CORE_OPTIONS_DISPLAY`; their declared options are not dynamically hidden by the core.
- Virtual Jaguar hides both ports’ detailed mapping options while `virtualjaguar_alt_inputs=disabled`.
- Once Virtual Jaguar content is loaded, `virtualjaguar_cd_bios_type`, `virtualjaguar_cd_boot_mode`, `virtualjaguar_cd_read_speed`, `virtualjaguar_cd_trace` and `virtualjaguar_memory_track` are visible only for CD content; `virtualjaguar_bios` is visible only for cartridge content. Before loading content, both groups remain visible.
- Atari800 declares `disabled` as the default of `atari800_ntscpal`, although its only declared values are `NTSC` and `PAL`. This is recorded as a source anomaly; GW GUI must not present `disabled` as a valid video standard.
