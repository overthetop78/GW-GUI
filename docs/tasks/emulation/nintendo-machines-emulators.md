Validation du 8 octobre 2026 :

- 55 émulateurs et associations du tableau couvertes ; 57 tests Nintendo réussis.
- 12 fenêtres OpenGL détruites, dont 6 interruptions ; 6 créations OpenGL refusées sans objet USER supplémentaire.
- FCEUmm, fixNES, Mesen, Nestopia, QuickNES et RustyNES chargent le programme NES libre de vérification et produisent des frames.
- Mesen2 refuse ce même programme, aussi par un appel direct à son API C indépendant du transport C#. Ce résultat ne valide pas son chargement de jeux ; les autres cœurs n’ont pas tous été testés avec un jeu.
- Build Debug avec les huit modules réussi ; exécutable et huit modules présents dans `build/Debug/GW GUI`.
- Ressources traduites avec Argos dans toutes les langues ; invariants conservés dans la base et caractères traditionnels pour `zh-Hant`.
- `git diff --check` réussi. Les tests ont signalé NU1900 pour la consultation des données de vulnérabilité NuGet ; le build final a réussi.
