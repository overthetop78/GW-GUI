# GW GUI คู่มือผู้ใช้

GW GUI เป็นโปรแกรมวินโดวส์สําหรับอ่าน, เขียน, แปลงภาพ, และจําลองภาพ มันควบคุมได้ Greaseweazle ฮาร์ดแวร์, ทํางานกับแฟ้มอิมเมจของดิสก์ผ่านกลไกภายในของมัน, และประมวลผลการปรับแต่งเครื่องจําลองการทํางาน

ส่วนเสริมนี้ ใช้อธิบายส่วนติดต่อผู้ใช้แบบภาษาอังกฤษที่แสดงอยู่ในรุ่นปัจจุบันของโปรแกรม มี การ เขียน เป็น แหล่ง ข้อมูล ของ คู่มือ ผู้ ใช้ ที่ พิมพ์ ได้: ภาพ หน้าจอ แสดง ถึง การ ควบคุม ส่วน ข้อ ความ ที่ อยู่ รอบ ๆ นั้น อธิบาย ว่า จะ เลือก อะไร, ทําไม จึง เลือก มัน, และ จะ พิสูจน์ ผล อย่าง ไร.

> **สิ่งสําคัญ:** การอ่านดิสก์ไม่เสียหาย การ เขียน, การ ลบ ล้าง, การ ปรับ ปรุง บริษัท, และ เครื่อง มือ เครื่อง มือ บาง อย่าง สามารถ แก้ไข สื่อ หรือ อุปกรณ์ ได้. อ่านคําเตือนที่แนบมากับขั้นตอนที่เกี่ยวข้องก่อนที่จะคลิก ** ประมวลผล**.

### วิธี ใช้ เครื่อง ชี้ นํา นี้

ถ้านี่เป็นครั้งแรกของคุณ GW GUIเสร็จสมบูรณ์ [เริ่ม](#getting-started)ต่อไปนี้ [กําลังอ่านดิสก์](#reading-a-disk)หากโปรแกรมถูกปรับแต่งไว้แล้ว ให้ไปยังบทสําหรับปฏิบัติการที่คุณต้องการทําโดยตรง ตัวเลือกต่าง ๆ นี้ ใช้เป็นตัวอ้างอิง เมื่อกระบวนการนี้สั่งเปลี่ยนไดรฟ์, เครื่องยนต์, โพรไฟล์, หรือเครื่องจําลองภาพ

ชื่ออินเทอร์เฟสจะถูกแสดงใน **ตัวหนา** ชื่อแฟ้ม, พาธ, คําสั่ง, และค่าตามตัวอักษรจะถูกแสดงเป็น `code`ข้อสังเกตอธิบายพฤติกรรมปกติ; เตือนให้ระบุการปฏิบัติการที่อาจจะเปลี่ยนแผ่นดิสก์, ตัวควบคุม, หรือการปรับแต่งที่เก็บไว้

## การ เข้าใจ ความ ไหล เวียน ของ งาน

GW GUI แยกการประมวลผลภาพด้วยดิสก์ออกจากปฏิบัติการกับแฟ้มภาพ:

| เป้าหมาย | นําเข้า | ส่งออก | หน้าแนะนํา |
|---|---|---|---|
| เก็บแผ่นฟลอปปี้ | ดิสก์ทางกายภาพ | แฟ้มอิมเมจ | **อ่าน** |
| สร้างแผ่นฟลอปปีใหม่อีกครั้ง | แฟ้มอิมเมจ | ดิสก์ทางกายภาพ | **เขียน** |
| เปลี่ยนรูปแบบรูปภาพ | แฟ้มอิมเมจ | แฟ้มรูปภาพหนึ่งภาพหรือหลายตัว | **เปลี่ยน** |
| แสดงแทร็กเสียงและความผิดปกติ | แฟ้มอิมเมจ | การวิเคราะห์ภาพ | **การถ่ายภาพ** |
| เรียกดูแฟ้มที่ถูกจัดเก็บไว้ในภาพ | ระบบอิมเมจ/ file ที่รองรับ | แฟ้มและไดเรกทอรี | **Disk Explorer** |
| วิเคราะห์ไดรว์หรือตัวควบคุม | Greaseweazle ฮาร์ดแวร์ | การวัดหรือสถานะ | **เครื่องมือ** |
| ประมวลผลเครื่องเสมือนที่บันทึกไว้ | บันทึกการปรับแต่งเครื่อง | วาระงานการจําลอง | **จําลอง** |

เพื่อการอนุรักษ์ อย่างแรก จงจับดิบ และทําให้มันไม่เปลี่ยนแปลง สร้างและซ่อมแซมสําเนางานจากอาจารย์คนนั้น นี้จะหลีกเลี่ยงการอ่านซ้ําและรักษาข้อมูล ที่รูปแบบภาคอาจจะเก็บไว้ไม่ได้

## เริ่ม

### เงื่อนไข

- หน้าต่างที่มี Microsoft .NET พื้นที่ทํางานที่โปรแกรมต้องการ
- A Greaseweazle ควบคุมปฏิบัติการของฟลอปปี้ดิสก์
- ตําแหน่งที่ปรับแต่ง `gw.exe` เมื่อใช้ Greaseweazle Host Tools เครื่องยนต์
- ได้รับตามกฏหมาย ROM แฟ้มที่เครื่องจําลองต้องการ

โปรแกรมตรวจสอบเมื่อเริ่มทํางานที่ .NET ถ้ามันขาดหายไป โปรดติดตามการแจ้งเตือนของการติดตั้ง แล้วเริ่มการทํางานใหม่อีกครั้ง GW GUI.

### ก่อนเชื่อมต่อฮาร์ดแวร์

Check ต่อไปนี้ก่อนที่จะทําปฏิบัติการ score- disk:

1. เชื่อมต่อ Greaseweazle ควบคุม คอก สัตว์ USB พอร์ต
2. เชื่อมต่อสายฟลอปปี้กับทิศทางที่ถูกต้อง
3. เชื่อมต่อแหล่งจ่ายไฟของไดรฟ์ก่อนที่จะใส่สื่อที่มีคุณภาพลงไป
4. ยืนยันขนาดไดรฟ์และความหนาแน่นของดิสก์
5. ป้องกันแผ่นต้นทางเมื่อเป็นไปได้

GW GUI ไม่ อาจ ป้องกัน ความ เสีย หาย ที่ เกิด จาก การ ขับ รถ แท็กซี่ ที่ ไม่ ถูก วิธี, พลัง ขับ ขี่ ที่ ไม่ เหมาะ สม, หรือ แรง ขับ ที่ ไม่ ปลอด ภัย แบบ เครื่องจักร. ทดสอบฮาร์ดแวร์ที่ไม่คุ้นเคยกับดิสก์ที่ใช้ได้ก่อน

### เปิดตัวครั้งแรก

1. เปิด `gwgui.exe`.
2. เปิด **ตัวเลือก**.
3. ใน **ตัวควบคุมและไดรฟ์** สแกนตัวควบคุมและปรับแต่งไดรฟ์
4. ตรวจสอบหรือเลือกพาธไปยัง `gw.exe`.
5. ใน **เครื่องยนต์** เลือกเครื่องยนต์ที่จะดําเนินการแต่ละปฏิบัติการ
6. กลับไปที่หน้าต่างหลักและเลือกแท็บปฏิบัติการที่ต้องการ

### ยืนยันการตั้งค่าที่พร้อม

การตั้งค่าการทํางานควรจะแสดงตัวควบคุมและไดรฟ์ในแถบสถานะ ตัวอย่างเช่นหมายเลขไดรฟ์ ขนาด ความหนาแน่น และ COM พอร์ต ใน **ตัวเลือกต่าง ๆ > ตัวควบคุมและไดรฟ์** เครื่องควบคุมควรจะทําเครื่องหมาย **มี** และไดรฟ์ ** ปรับแต่ง **วิ่ง ** ข้อมูลตัวควบคุม** ก่อนที่จะอ่านสื่อที่มีคุณค่า หากคุณต้องการตรวจสอบการสื่อสาร โดยไม่ต้องเปลี่ยนแผ่น

### เลือกเครื่องยนต์

GW GUI สามารถเปิดเผยวิธีปฏิบัติได้มากกว่าหนึ่งอย่าง เดอะ **Greaseweazle Host Tools** กลไกเรียกค่าปรับแต่ง `gw.exe`สืบค้นภายใน GW GUI ส่วนจับของเครื่องยนต์สนับสนุนการทํางานภายในโปรแกรม การคัดเลือกเครื่องยนต์มีความชัดเจนและอิสระในการอ่าน, การเขียน, การแปลง, และ Disk Explorer. ถ้าปฏิบัติการไม่รองรับเครื่องยนต์ที่เลือกไว้ GW GUI รายงาน สภาพ ดัง กล่าว แทน ที่ จะ เปลี่ยน เครื่อง ยนต์ โดย อัตโนมัติ.

## หน้าต่างหลัก

หน้าต่างหลักจะจัดกลุ่มการทํางานหลักเป็นเจ็ดแท็บ:

- **อ่าน** สร้างภาพจากดิสก์
- **เขียน** เขียนภาพลงในดิสก์
- **เปลี่ยน** แปลงฟอร์แมตของดิสก์แบบเดียวเป็นรูปแบบผลลัพธ์แบบหนึ่งหรือมากกว่า
- **การถ่ายภาพ** แสดงแทร็กเสียงและฟลักซ์หรือข้อมูลที่ถูกเข้ารหัสไว้
- **Disk Explorer** การเรียกดูรองรับระบบแฟ้มและเนื้อหาบนดิสก์
- **เครื่องมือ** จัด ให้ มี การ บํารุง รักษา และ สั่ง การ วินิจฉัย อาวุธ.
- **จําลอง** จัดการและทํางานบันทึกเครื่องจักรเลียนแบบ

คอนโซลที่อยู่ด้านล่าง จะแสดงการประมวลผลคําสั่งและผลลัพธ์ที่ออกมา แถบสถานะรายงานไดรว์, โพรไฟล์ และสถานะปัจจุบัน

### กําลังอ่านส่วนติดต่อผู้ใช้

หน้าปฏิบัติการส่วนใหญ่จะเป็นไปตามรูปแบบเดียวกัน:

1. **แหล่งหรือปลายทาง** ควบคุมการกําหนดพื้นที่ดิสก์, อิมเมจ, หรือโฟลเดอร์
2. **ควบคุมรูปแบบ** เลือกการตรวจสอบอัตโนมัติ หรือรูปแบบเครื่องและรูปแบบโดยตรง
3. **ควบคุมโพรไฟล์** ปรับใช้การตั้งค่าที่ใช้งานได้
4. **ตั้งค่าขั้นสูง** เปิดเผยพารามิเตอร์ที่ปกติจะเลือก
5. **ประมวลผล** เริ่มปฏิบัติการ
6. เดอะ **คอนโซล** แสดง คําสั่ง, ความ ก้าว หน้า, คํา เตือน, และ ข้อ ผิด พลาด ที่ เกิด ขึ้น.

เดอะ **ประมวลผล** ปุ่ม ไม่ได้หมายความว่า ค่าทั้งหมดจะปลอดภัยสําหรับแผ่นที่ใส่เข้าไป จง ทบทวน จุด หมาย ปลาย ทาง และ เลือก ไดรฟ์ ก่อน จะ ทํา การ เขียน หรือ บํารุง รักษา.

### แถบสถานะและคอนโซล

ด้านซ้ายของแถบสถานะ ระบุว่ามีไดรว์อยู่ แสดงโพรไฟล์ที่ทํางานอยู่เมื่อเลือกใช้ ตัวบ่งชี้ของรัฐแจ้งว่าโปรแกรมพร้อมหรือไม่ว่าง คอนโซลไม่ได้เป็นเพียงการวินิจฉัย: มันเป็นบันทึกที่ถูกต้องของคําสั่งที่ส่งไปยังเครื่องยนต์ที่เลือก ใช้ตัวควบคุมการคัดลอกของมันเมื่อคุณจําเป็นต้องรักษาหรือใช้คําสั่งร่วมกัน

## กําลังอ่านดิสก์

เปิดสิ **อ่าน** แท็บเพื่อจับภาพแผ่นฟลอปปีทางกายภาพในรูปแบบอิมเมจ

<p align="center"><img src="images/main-read-en.png" alt="แท็บสําหรับอ่าน" width="78%"></p>

### กระบวนการพื้นฐาน

1. แทรกแผ่นต้นฉบับลงในไดรฟ์ที่ปรับแต่งแล้ว
2. เลือกประเภทของภาพ:
   - **อิมเมจ Raw (SCP)** รักษาข้อมูลระดับฟลักซ์
   - **ฟอร์แมตดิสก์ที่รู้จัก** สร้างรูปภาพโดยใช้อุปกรณ์และรูปแบบที่เลือก
3. เลือกโฟลเดอร์ปลายทาง
4. ป้อนชื่อแฟ้มผลลัพธ์
5. เลือกโพรไฟล์หากต้องการ
6. คลิก **ประมวลผล**.

คอนโซลแสดงคําสั่งและความคืบหน้าที่แน่นอน อย่าลบแผ่นดิสก์ หรือตัดการเชื่อมต่อกับตัวควบคุม จนกว่าปฏิบัติการจะเสร็จสิ้น

### เลือกประเภทของผลลัพธ์

ใช้ **อิมเมจ Raw (SCP)** เมื่อ วัตถุ ประสงค์ นั้น เป็น การ จับ กุม, วิเคราะห์, ฟื้น ตัว, หรือ เปลี่ยน แปลง ใน ภาย หลัง. ภาพดิบบันทึกเวลาและการปฏิวัติหลายรอบ ซึ่งมีประโยชน์ต่อการรูปแบบที่ผิดปกติ ส่วนที่อ่อนแอ แผนป้องกัน และสื่อที่เสียหาย

ใช้ **ฟอร์แมตดิสก์ที่รู้จัก** เมื่อคุณรู้จักครอบครัวดิสก์แล้ว และต้องการภาพลักษณ์ของภาคที่ใช้ได้โดยตรง ทาง เลือก นี้ อาจ เล็ก กว่า และ ง่าย กว่า ที่ จะ เปิด ใน ซอฟต์แวร์ อื่น ๆ แต่ นั่น แสดง ถึง ผล ที่ ได้ รับ การ ถอด รหัส แทน ที่ จะ เป็น ราย ละเอียด ทุก อย่าง ที่ ได้ รับ จาก ไดรฟ์.

เมื่อไม่แน่ใจ ให้สร้างอิมเมจดิบก่อน คุณสามารถแปลงมันในภายหลังโดยไม่ต้องอ่านแผ่นอีกครั้ง

### โฟลเดอร์, ชื่อแฟ้ม, และโพรไฟล์

เดอะ **โฟลเดอร์** เป็นไดเรกทอรีปลายทาง เดอะ ** ชื่อแฟ้ม** ควร ระบุ ตัว แผ่น ดิสก์ โดย ไม่ ต้อง อาศัย บัตร เท่า นั้น. ชื่อทางภูมิศาสตร์ที่มีประโยชน์ มีชื่อเรื่อง,หมายเลขดิสก์ หรือด้าน, และบันทึกเงื่อนไขเมื่อปรับใช้ ไม่ต้องเพิ่มนามสกุลรูปแบบที่ขัดแย้งกับรูปแบบการแสดงผลที่เลือกไว้

A **โพรไฟล์** ปรับใช้ชุดพารามิเตอร์การอ่านที่บันทึกไว้ เลือกหนึ่งเมื่อคุณรู้ว่ามันบรรจุอะไร เดอะ ** ค่าปริยาย** โพรไฟล์เหมาะกับความพยายามครั้งแรก โพรไฟล์การฟื้นตัวแบบพิเศษ อาจจงใจอ่านการปฏิวัติหรือช่วงต่าง ๆ และใช้เวลานานกว่านั้น

### ตั้งค่าขั้นสูง

ขยาย **ตั้งค่าขั้นสูง** เพื่อเข้าใช้รูปแบบที่ระบุหรือพารามิเตอร์ของผู้เชี่ยวชาญ ปล่อยให้ค่าเหล่านี้ไม่เปลี่ยนแปลง จนกว่าแผ่นดิสก์จะต้องการช่วงของเพลง, จํานวนการหมุน, หรือตัวเลือกควบคุม

ค่าที่มีขั้นสูงทั่วไป รวมถึง:

| ตั้งค่า | วัตถุประสงค์ | เมื่อจะเปลี่ยน |
|---|---|---|
| ช่วงของเพลง | จํากัดกระบอกและหัวที่จะอ่าน | สื่อเดี่ยว, เรขาคณิตที่ผิดปกติ, หรือใบกู้เป้าหมาย |
| การ ปฏิวัติ | ควบคุมจํานวนการหมุน | เพิ่มความไม่เสถียรหรือการป้องกันแทร็กเสียง; ลดความเร็วเฉพาะเมื่อเหมาะสม |
| อาร์กิวเมนต์อัจฉริยะ | ผ่านพารามิเตอร์ของกลไกเพิ่มเติม | เมื่อมีการส่งเอกสาร Greaseweazle คําแนะนํา |

### การตรวจสอบการอ่านที่ประสบความสําเร็จ

อย่าพึ่งเฉพาะการไม่มีกล่องข้อผิดพลาดเท่านั้น หลังจากคําสั่งเสร็จสมบูรณ์แล้ว:

1. ยืนยันว่ามีแฟ้มส่งออกอยู่แล้ว และไม่ใช่แฟ้มว่าง
2. อ่านบรรทัดคอนโซลสุดท้ายสําหรับเพลงที่ล้มเหลวหรือหายไป
3. เปิดภาพใน **การถ่ายภาพ** เพื่อตรวจสอบว่าทั้งสองฝั่ง และช่วงของเพลงที่คาดหวัง มีข้อมูลอยู่
4. เปิดใน **Disk Explorer** เมื่อรองรับการใช้งานระบบแฟ้ม
5. เก็บบันทึกปฏิบัติการด้วย การจับกุมแบบโบราณ

ถ้า มี การ อ่าน ซ้ํา อีก จง เก็บ ไว้ แต่ ละ ตัว แทน ที่ จะ เขียน ตัว แรก มาก เกิน ไป. ความแตกต่างอาจมีประโยชน์ ระหว่างการฟื้นตัว

## กําลังเขียนดิสก์

เปิดสิ **เขียน** แท็บเพื่อเขียนภาพที่มีอยู่ก่อนแล้วไปยังแผ่นฟลอปปี้

<p align="center"><img src="images/main-write-en.png" alt="แท็บการเขียน" width="78%"></p>

### กระบวนการพื้นฐาน

1. แทรกแผ่นปลายทาง
2. เลือกภาพต้นฉบับด้วย **เลือก**.
3. ยืนยันรูปแบบที่ตรวจพบ
4. เลือกโพรไฟล์หากต้องการ
5. คลิก **ประมวลผล**.

กําลังเขียนแทนที่ข้อมูลจากแผ่นปลายทาง ตรวจสอบไดรว์และอิมเมจที่เลือกไว้ก่อนที่จะเริ่มการทํางาน

> **คําเตือน:** การเขียนเป็นการทําลาย มันแทนที่ข้อมูลแม่เหล็กบนแผ่นปลายทาง ใช้แฟ้มจัดเก็บต้นทางที่มีการป้องกันด้วยการเขียน และแยกแผ่นปลายทางออกจากกัน เมื่อไรก็ตามที่เป็นไปได้

### ก่อนทําการเขียน

กาเลือกสี่รายการก่อนที่จะคลิก **ประมวลผล**:

1. **ภาพ:** พาธที่เลือกไว้คือภาพต้นฉบับที่ต้องการ
2. **ดิสก์:** ดิสก์ในไดรว์อาจถูกเขียนทับอย่างปลอดภัย
3. **ไดรฟ์:** ขนาดและความหนาแน่นที่ปรับแต่ง ให้เหมาะกับสื่อปลายทาง
4. **รูปแบบ:** การตรวจสอบอัตโนมัติหรือรูปแบบที่เลือกด้วยตนเองตรงกับภาพ

หากยังไม่ได้ทดสอบภาพต้นฉบับ โปรดเปิดภาพ **การถ่ายภาพ ** หรือ ** Disk Explorer** ก่อน การเขียนที่ประสบความสําเร็จไม่สามารถซ่อมแซมภาพต้นฉบับที่ยังไม่เสร็จได้

### การตรวจสอบและแก้ไขเพลง

หลังจากเลือกภาพแล้ว **แทร็กภาพ ** เปิดการแสดงแทร็ค ** แก้ไข** เปิดโปงการแก้ไขภาพที่รองรับก่อนทําการเขียน การกระทําที่มีอยู่จะขึ้นอยู่กับรูปแบบและเครื่องยนต์ที่เลือก

### กําลังตรวจสอบดิสก์ที่เขียนได้

เมื่อเครื่องยนต์สนับสนุนการตรวจสอบ ใช้มันกับสื่อที่สําคัญ ไม่เช่นนั้น จะอ่านแผ่นดิสก์ที่เขียนกลับไปยังภาพใหม่ และเปรียบเทียบเนื้อหาที่ถอดรหัสแล้ว หรือตรวจสอบมัน **การถ่ายภาพ** เก็บการตรวจสอบแยกจากภาพต้นฉบับ เพื่อไม่ให้ภาพต้นฉบับถูกเขียนทับ

หาก การ เขียน ล้ม เหลว ใน ข้อ ความ ที่ เสมอ ต้น เสมอ ปลาย ให้ ตรวจ สอบ สภาพ ของดิสก์, ความ หนา แน่น, ความ สะอาด, และ การปรับแต่ง การ ขับ ขี่. หากเกิดความล้มเหลวขึ้นอย่างสุ่ม ให้ตรวจสอบ USB เสถียรภาพและควบคุมการสื่อสาร

## กําลังแปลงภาพจากดิสก์

เดอะ **เปลี่ยน** แท็บเปลี่ยนภาพต้นฉบับเป็นรูปแบบต่าง ๆ ของปลายทาง

<p align="center"><img src="images/main-conversion-en.png" alt="แท็บการแปลง" width="78%"></p>

### กระบวนการพื้นฐาน

1. เลือกภาพต้นฉบับ
2. ตัวเลือกต่าง ๆ ให้ชื่อที่ส่งออก
3. เลือกครอบครัวเครื่องจักร
4. เลือกรูปแบบการแสดงผลและส่วนขยายต่าง ๆ ที่ออกหนึ่งรูปแบบหรือมากกว่า
5. เปิด **เพิ่มป้ายกํากับ** หากชื่อแฟ้มควรใช้รูปแบบแท็กปรับแต่ง
6. คลิก **ประมวลผล**.

เดอะ **เลือก ** รายการผลลัพธ์ที่ร้องขอ ** การย้ายแฟ้ม** การตั้งค่าการทํางานที่ทุ่มเทให้กับการย้ายแฟ้ม ที่รองรับ แทนการทําการแปลงภาพมาตรฐาน

### กําลังเลือกรูปแบบ

เดอะ **เครื่อง ** รายการกรองรูปแบบที่แสดงใน ** รูปแบบ** แผง ชื่อแฟ้มที่ใช้อธิบายการจัดวางดิสก์แบบตรรกะ ส่วนนามสกุลนั้น จะเป็นตัวอธิบายส่วนส่งออก บาง รูป แบบ สามารถ ใช้ แทน ได้ ด้วย การ ต่อ เติม มาก กว่า หนึ่ง ครั้ง และ ภาชนะ บาง ชนิด ไม่ อาจ เก็บ รักษา คุณสมบัติ ทุก อย่าง ของ แหล่ง ดิบ ได้.

เลือกผลลัพธ์ที่คุณต้องการ มีหลายรูปแบบที่มีประโยชน์เมื่อสร้างตัวต้นแบบแบบโบราณ, แบบจําลองที่เข้ากันได้, และสําเนาสําหรับเครื่องมือวิเคราะห์อีกอันในการดําเนินการครั้งเดียว

### ชื่อแฟ้มและป้ายกํากับส่งออก

**ชื่อที่ส่งออก ** ให้คุณควบคุมชื่อฐานที่สร้างสําหรับรูปแบบที่เลือกไว้ ** เพิ่มป้ายกํากับ ** ใช้รูปแบบชื่อแฟ้มที่ปรับแต่งมา ** ตัวเลือกต่าง ๆ > ค่าทั่วไป**ป้ายกํากับต่าง ๆ สามารถเข้ารหัสตระกูล, รูปแบบ, ส่วนขยาย, วันที่, หรือเวลาได้ แสดงตัวอย่างตัวอย่างต่าง ๆ ในตัวเลือก ก่อนที่จะทําการแปลงชุดขนาดใหญ่ เพื่อให้ชื่อแฟ้มมีชื่อเดียวกันเสมอ

### กําลังตรวจสอบผลการแปลง

สําหรับผลลัพธ์แต่ละรายการที่ร้องขอ:

1. ยืนยันการสร้างแฟ้มขึ้นมา
2. ตรวจสอบคอนโซลสําหรับเพลงหรือส่วนต่าง ๆ ที่ไม่สามารถถอดรหัสได้
3. เปิดผลลัพธ์ใน **Disk Explorer** ถ้ามันบรรจุระบบแฟ้มที่รองรับอยู่
4. จง เทียบ ความ จุ และ เนื้อหา ที่ คาด หมาย ได้ กับ แหล่ง ที่ มา.

การ เปลี่ยน แปลง จะ สําเร็จ ได้ ขณะ ที่ รายงาน การ สูญ เสีย ข้อมูล ซึ่ง มี อยู่ ใน รูป แบบ ของ จุด หมาย ปลาย ทาง. ปรับเทียบภาพต้นฉบับกับภาพต้นฉบับ แม้ภาพที่ถูกดัดแปลงมาจะถูกปรับให้ถูกต้องก็ตาม

## สร้างภาพจากดิสก์

เดอะ **การถ่ายภาพ** แท็บ แสดงโครงสร้างและการกระจายข้อมูลของภาพ

<p align="center"><img src="images/main-visualization-en.png" alt="แถบปรับภาพ" width="78%"></p>

1. คลิก **เปิดอิมเมจของดิสก์**.
2. เก็บไว้ **ตรวจสอบอัตโนมัติ** เปิดหรือเลือกรูปแบบเครื่องจักรด้วยตนเอง
3. ใช้ **ขยายส่วนเชื่อมโยง** เพื่อให้ทั้งสองฝั่งอยู่ระดับซูมเดียวกัน
4. ใช้ **ตั้งค่าใหม่** เพื่อฟื้นฟูมุมมองเริ่มต้น
5. เปิด **สารวัตร** สําหรับรายละเอียดเกี่ยวกับพื้นที่ที่เลือก

ตํานานนี้จําแนก ฟลักซ์ปกติได้ ระยะสั้นและเปลี่ยนแปลงยาว ส่วนหัว ถอดรหัสข้อมูล และตรวจพบความผิดปกติ แฟ้มภาพดิบอาจจะมีข้อมูลที่ไม่สามารถถอดรหัสมายังระบบแฟ้มที่รู้จักได้ แต่ยังสามารถตรวจสอบได้ที่นี่

### กําลังคํานวณมุมมอง

แผ่น กลมขนาดใหญ่แต่ละแผ่น แสดงด้านจานหนึ่งด้าน ศูนย์ระบุด้านและสถานะของข้อมูลปัจจุบัน ตําแหน่งที่สอดคล้องกันตรงกับแทร็ก สี เป็น ลักษณะ เฉพาะ ของ ภูมิภาค ที่ มี การ ตรวจ พบ ตาม ตํานาน. เห็นภาพมีวัตถุประสงค์ที่จะตอบคําถามเช่น

- ภาพนี้มีข้อมูลด้านใดด้านหนึ่งหรือไม่
- มีรางรถไฟที่คาดหวังไว้มั้ย
- ความ ผิด ปกติ ถูก แยก ไว้ ต่าง หาก หรือ ไม่ ก็ ข้าม ดิสก์ ซ้ํา แล้ว ซ้ํา อีก ไหม?
- การตรวจจับอัตโนมัติ ระบุว่าเป็นเครื่องจักรและรูปแบบที่สมเหตุสมผลหรือไม่?

สีที่ผิดปกติคือเหตุผลในการตรวจสอบพื้นที่ ไม่ใช่ข้อพิสูจน์ว่าดิสก์ไม่สามารถใช้ได้ การป้องกันแบบเลียนแบบ รูปแบบที่ไม่มาตรฐาน การบันทึกที่อ่อนแอ และส่วนที่เสียหาย สามารถสร้างโครงสร้างที่แตกต่าง

### ลําดับการตรวจสอบแนะนํา

เริ่มด้วยการย่อขยายที่เชื่อมโยง เพื่อเปรียบเทียบทั้งสองฝั่งในระดับเดียวกัน เลือกเขตที่น่าสงสัย, เปิด **สารวัตร** และเปรียบเทียบมันกับร่องรอยข้างเคียง หากผลปรากฏว่าเป็นปัญหาในการตรวจจับ ให้ปิดการตรวจสอบอัตโนมัติและเลือกเครื่องและรูปแบบที่รู้จัก กลับไปยังการตรวจสอบโดยอัตโนมัติ หลังจากการทดสอบ ดังนั้นการตั้งค่าการบังคับจึงไม่ได้ถูกใช้อย่างบังเอิญกับภาพอื่น

## กําลังสํารวจเนื้อหาจากดิสก์

เดอะ **Disk Explorer** การเรียกดูแท็บต่าง ๆ รองรับภาพจากดิสก์เป็นโครงสร้างแฟ้ม

<p align="center"><img src="images/main-disk-explorer-en.png" alt="Disk Explorer แท็บ" width="78%"></p>

1. เปิดภาพหรืออ่านแผ่นที่มีอยู่ก่อนแล้ว
2. เก็บไว้ **ตรวจสอบอัตโนมัติ** เปิดการทํางาน จนกว่าคุณจะต้องการที่จะบังคับเครื่องหรือรูปแบบ
3. ตรวจ ดู ข้อมูล ปริมาตร: ระบบ, ระบบ, การ ป้องกัน, ระบบ ไฟล์, ความ จุ, พื้นที่ ว่าง, และ สิ่ง ของ ต่าง ๆ.
4. เรียกดูไดเรกทอรีในถาดด้านซ้าย
5. เลือกรายการที่จะให้แสดงรายละเอียดในถาดด้านขวา

หากยังไม่รองรับรูปแบบของภาพหรือระบบแฟ้ม ให้ใช้ **การถ่ายภาพ** เพื่อตรวจสอบโครงสร้างดิบแทน

### การเข้าใจพาเนล

การ สรุป ภาพ บน พรรณนา ภาพ ที่ ได้ รับ การ ติด ตั้ง และ การ ตรวจ สอบ ความ ดัง. แผงด้านล่างซ้ายบรรจุโครงสร้างไดเรกทอรี รายการในตารางกลางรายการในไดเรกทอรีที่เลือกไว้ โดยใช้ชื่อ, แก้ไขวันที่, ประเภท, และขนาด แสดงรายละเอียดของรายการที่เลือกไว้

Disk Explorer ไม่ ได้ หมาย ความ ว่า ร่อง รอย ทั้ง หมด ถูก ถอด ออก อย่าง สมบูรณ์ แบบ. ใช้การสรุปค่าปริมาตรและจํานวนรายการ เป็นการตรวจสอบความจุอย่างรวดเร็ว แล้วเปิดเอกสารตัวแทน หรือเปรียบเทียบมันกับรายการไดเร็กทอรีที่รู้จักกัน เมื่อมีการบันทึกค่าถูกต้อง

### เมื่อไม่มีอะไรเกิดขึ้น

ยืนยันว่าพาธของภาพถูกต้อง จากนั้นตรวจสอบเครื่องตรวจจับและรูปแบบ ภาพ ที่ ใช้ ได้ จริง อาจ มี ระบบ ไฟล์ ที่ ไม่ ได้ รับ การ สนับสนุน หรือ ไม่ ได้ รับ ความ เสีย หาย ซึ่ง ใน กรณี นั้น นัก สํารวจ สามารถ คง ไว้ ซึ่ง ความ ว่าง เปล่า แม้ ว่า จะ เป็น อย่าง นั้น **การถ่ายภาพ** แสดงข้อมูลบันทึก อย่าเขียนทับหรือละทิ้งภาพต้นฉบับ โดยอิงมาจากผู้สํารวจที่ว่างเปล่าเท่านั้น

## การใช้เครื่องมือ

เดอะ **เครื่องมือ** กลุ่มแท็บ Greaseweazle งานซ่อมบํารุง

<p align="center"><img src="images/main-tools-en.png" alt="แท็บเครื่องมือ" width="78%"></p>

เลือกคําสั่งจากรายการทางด้านซ้าย ทบทวนพารามิเตอร์แล้วคลิก **ประมวลผล** ควรใช้คําสั่งปรับโครงสร้างหรือเปลี่ยนฮาร์ดแวร์ หลังจากตรวจสอบตัวควบคุมและไดรฟ์แล้วเท่านั้น

กล่องเครื่องมือส่วนใหญ่มีพื้นที่ 3 พื้นที่: พารามิเตอร์อยู่ด้านบน, สถานะ และพื้นที่นอกระบบดิบตรงกลาง และคําสั่งที่สร้างที่ด้านล่าง การเปลี่ยนส่วนแสดงตัวอย่างคําสั่ง เนื่องจากตัวเลือกถูกเปิดใช้งาน พารามิเตอร์ที่ควบคุมไม่ได้ ปกติแล้วหมายถึง “อย่าแก้ไขค่านี้" ส่วนพารามิเตอร์ที่กาเลือกนั้น จะรวมค่าในคําสั่งด้วย

กล่อง วินิจฉัย โรค ของ แต่ ละ คน มี การ พรรณนา ไว้ ใน [การ วินิจฉัย และ การ บํารุง รักษา ฮาร์ดแวร์](#hardware-diagnostics-and-maintenance).

## จําลอง

### เปิดเครื่องช่วยชีวิต

เดอะ **จําลอง ** รายการแท็บบันทึกการปรับแต่งแล้ว เลือกหนึ่งแล้วคลิก ** เปิด**...เครื่องวิ่งแต่ละเครื่องปรากฏในแท็บของตัวเอง

<p align="center"><img src="images/main-emulation-welcome-en.png" alt="การจําลองหน้าจอ" width="78%"></p>

สร้างและแก้ไขเครื่องจักรใน **ตัวเลือกต่าง ๆ > จําลอง > การปรับแต่ง ** ถึง ** ตัวเลือกต่าง ๆ > จําลอง > Amiga**.

หากยังไม่มีการปรับแต่ง ให้สร้างตัวเลือกหนึ่งก่อน การปรับแต่งที่บันทึกไว้จะรวมรุ่นเครื่องจักร รุ่นจําลอง ROM, ความทรงจํา, วีดีโอ, เสียง, โกดัง, และข้อมูลเข้า การบันทึกการปรับแต่งไม่ได้เริ่มการทํางาน; กลับไปยังหลัก **จําลอง ** แท็บแล้วคลิก ** เปิด**.

### ควบคุมการทํางานเครื่อง

<p align="center"><img src="images/main-emulation-running-en.png" alt="ประมวลผลเครื่องเลียนแบบ" width="78%"></p>

แถบเครื่องมือรันเครื่อง ให้พลังงาน, หยุด, ตั้งค่าใหม่, บันทึกสถานะ, เรียกโหลด, จับภาพ, และควบคุมการแสดงผล บทความ นี้ ยัง แสดง ให้ เห็น ด้วย ว่า:

- ปุ่มพิมพ์ลัดที่ใช้บันทึกด่วนและโหลดอย่างรวดเร็ว
- ตัวแปลการทํางาน เช่น Direct3D 11;
- ปุ่มพิมพ์ลัดเต็มจอและปุ่มพิมพ์ลัดของเมาส์
- ระบบเสียง, ตัวควบคุม, และสถานะเมาส์;
- ความละเอียดปัจจุบัน อัตรารีเฟรช และอัตราเฟรม

แถบดิสก์ที่ด้านล่างของการแสดงผลการจําลอง จะทําการลบสื่อสําหรับไดรฟ์ที่คัดลอกได้ การกําหนดแป้นพิมพ์สามารถเปลี่ยนแปลงได้ **ตัวเลือกต่าง ๆ > จําลอง > ปุ่มพิมพ์ลัด** ส่วนการใช้แป้นพิมพ์, เมาส์ และตัวควบคุมต่าง ๆ ถูกปรับแต่งในรูปแบบที่สอดคล้องกัน Amiga แท็บ

### อ้างอิงแถบเครื่องมือ

| กลุ่มควบคุม | วัตถุประสงค์ |
|---|---|
| พลังและหยุดชั่วคราว | เริ่ม, หยุด, หยุด, หรือ ทํา เครื่อง เลียน แบบ ต่อ ไป |
| ตั้งค่าการควบคุมใหม่ | ทําการปรับค่าความนุ่มหรือการรีเซ็ตยาก ๆ |
| ควบคุมสถานะ | ประหยัด หรือ ขน ส่ง สภาพ ของ ตัวจําลอง เพื่อ ให้ ประสบ ความ สําเร็จ อย่าง รวด เร็ว |
| จับภาพ | บันทึกภาพของการแสดงผลแบบย่อ |
| แสดง | เปลี่ยนการแสดงหรือเข้าเต็มจอ |
| เตือนความจําทางช่องด่วน | แสดงปุ่มพิมพ์ลัดการบันทึก/ การโหลดที่ทํางานอยู่ |
| ตัววาด | รายงานข้อผิดพลาดของแบ็คเอนต์วิดีโอที่ทํางานอยู่ |
| เตือนความจําการนําเข้า | แสดงปุ่มเต็มจอและปุ่มพิมพ์ลัดของเมาส์ |
| ตัวบ่งชี้อุปกรณ์ | รายงานเสียง, ตัวควบคุม, และสถานะเมาส์ |
| ประสิทธิภาพ | รายงานขนาดผลลัพธ์, ปรับปรุงความถี่, และอัตราเฟรม |

### ออกจากจอเต็ม หรือปล่อยเมาส์ออกมา

แถบเครื่องมือจะแสดงปุ่มที่กําหนดให้ใช้อยู่ในปัจจุบัน ในการปรับแต่งตัวอย่าง **ขนาด Alt+ กลับ ** ผุดหน้าต่างเต็มจอ ** F12** ปล่อยเมาส์ ปฏิบัติกับค่าที่แสดงตามกฎหมาย เนื่องจากสามารถกําหนดปุ่มพิมพ์ลัดได้

### ใช้สื่อของฟลอปปี้

ไดรว์นี้ระบุแต่ละไดรว์ที่เลียนแบบ เช่น `DF0:`ใช้ตัวควบคุมสื่อเพื่อแทรก, เปลี่ยน, หรือไล่ภาพออก การส่งสื่อเปลี่ยนแปลงเฉพาะดิสก์ที่ถูกเสียบอยู่ของเครื่องเท่านั้น ซึ่งจะไม่เปลี่ยนค่านิยามการจัดเก็บข้อมูล ในเครื่องบันทึก จนกว่าจะมีการบันทึกการกระทํานั้น ๆ ไว้โดยตรง

## ตัวเลือกของโปรแกรม

เปิด **ตัวเลือก** จากหน้าต่างหลักเพื่อปรับแต่งโปรแกรม

### ค่าทั่วไป

<p align="center"><img src="images/options-general-en.png" alt="ตัวเลือกทั่วไป" width="72%"></p>

เดอะ **ค่าทั่วไป** แท็บบรรจุ:

- โฟลเดอร์ปริยายบนดิสก์
- ภาษาและชุดตกแต่ง
- รุ่นของชื่อแฟ้มสําหรับการแปลง
- กําหนดรูปแบบป้ายกํากับและรูปแบบที่เคยกําหนดเอง
- ตัวอย่างชื่อแฟ้มสดๆ

ตัวแปรแท็กรวมชื่อแหล่ง, ตระกูล, รูปแบบ, ส่วนขยาย, วันที่, และเวลา ใช้ปุ่มรีเซ็ตเพื่อเรียกคืนรูปแบบปริยาย

การปรับปรุงชื่อแฟ้มก่อนที่แฟ้มใด ๆ จะถูกสร้างขึ้น ใช้มันเพื่อตรวจสอบสัญลักษณ์ที่ซ้ํากัน, นามสกุลที่ขาดหายไป หรือชื่อคลุมเครือ รูปแบบการตั้งเองเมื่อเร็ว ๆ นี้ ทําให้มีสิทธิ์ในการใช้รูปแบบการตั้งชื่อก่อนหน้า โดยไม่แทนที่ชุดสําเร็จที่มีอยู่ในปัจจุบัน

### ปูมบันทึก

<p align="center"><img src="images/options-logs-en.png" alt="ตัวเลือกของปูมบันทึก" width="72%"></p>

การบันทึกสามารถตั้งค่าอิสระสําหรับแต่ละปฏิบัติการได้ สําหรับทุกหมวดหมู่ ให้เลือกว่าจะให้บันทึกปูมบันทึกหรือไม่ ให้ตั้งค่าขนาดแฟ้มสูงสุด และพิจารณาว่าจะให้คงปูมบันทึกตัวก่อนหรือไม่ ขนาดของ `0` หมายถึง ไม่จํากัด **เปิดโฟลเดอร์** เปิดไดเรกทอรีปูมบันทึกตัวปัจจุบัน

เปิด **คงปูมบันทึกก่อนหน้าไว้** เพื่ออนุรักษ์และวิเคราะห์งาน ที่ซึ่งประวัติของความพยายามหลายครั้ง ปิดการใช้งานมันเมื่อผลลัพธ์ล่าสุดมีประโยชน์เท่านั้น จํากัดขนาดสูงสุดที่จะใช้กับจัดเก็บแฟ้มปูมบันทึก ไม่ใช่เพื่อจับภาพภาพจากดิสก์

### ตัวควบคุมและไดรฟ์

<p align="center"><img src="images/options-controllers-and-drives-en.png" alt="ตัวควบคุมและไดรฟ์" width="72%"></p>

ใช้แท็บนี้กับ:

- ค้นหาตัวควบคุมการเชื่อมต่อ
- เพิ่มและเอาการปรับแต่งไดรว์ออก
- เลือกขนาดไดรฟ์, ความหนาแน่น และความเร็ว
- บันทึกการตั้งค่าฮาร์ดแวร์;
- เลือกหรือค้นหาโดยอัตโนมัติ `gw.exe`;
- ตรวจสอบและดาวน์โหลด Greaseweazle Host Tools ปรับปรุง
- คืนค่าพาธของโปรแกรมที่ประมวลผลมาแล้ว

จัดเก็บการตั้งค่าฮาร์ดแวร์ไว้ยังคงใช้ได้เมื่อไม่มีการใช้งานไดรว์ชั่วคราว

#### เพิ่มไดรว์

1. คลิก **ค้นหา** และรอให้ตัวควบคุมเชื่อมต่อปรากฏขึ้น
2. คลิก **เพิ่มไดรว์** หากไม่มีรายการไดรฟ์ที่ต้องการแล้ว
3. เลือก เลข ไดรฟ์ ที่ มี เหตุ ผล, ขนาด ร่าง กาย, ความ หนา แน่น ของ การ บันทึก, และ ความ เร็ว การ หมุน ของ มัน.
4. รักษาแถวไว้
5. ยืนยันว่ามันแสดงให้เห็น **มี** ถึง ** ปรับแต่ง**.

ใช้ตัวควบคุมถังขยะเท่านั้น เพื่อลบการปรับแต่งที่บันทึกไว้; มันไม่ยุติการเชื่อมต่อฮาร์ดแวร์ ถ้าตัวควบคุมแบบเดียวกันนี้เกิดขึ้น COM พอร์ตต่อจากนี้ จะทําการสแกนอีกครั้ง ก่อนที่จะสมมุติว่าพอร์ตที่เก็บยังใช้งานได้อยู่

#### กําลังจัดการ Greaseweazle Host Tools

**ค้นหา gw.exe ** ค้นหาสถานที่รู้จัก ** เลือก ** เลือกแฟ้มประมวลผลที่ต้องการ ** Check สําหรับการปรับปรุง ** ลําดับชั้นของรุ่นที่มีอยู่ โดยไม่ต้องแทนที่รุ่นที่ติดตั้งไว้ ** ดาวน์โหลดรุ่นล่าสุด ** ติดตั้งแพกเกจปัจจุบันและ ** ใช้พาธก่อนหน้า ** เรียกคืนตําแหน่งที่ปรับแต่งก่อนหน้านี้ หลังจากเปลี่ยนตัวประมวลผลแล้ว ให้วิ่ง ** ข้อมูลตัวควบคุม** เพื่อยืนยันรุ่นที่เลือก สามารถสื่อสารกับตัวควบคุมได้

### เครื่องยนต์

<p align="center"><img src="images/options-engines-en.png" alt="การเลือก" width="72%"></p>

เลือกเครื่องยนต์อิสระในการอ่าน, เขียน, เปลี่ยน, และ Disk Explorerเครื่องยนต์ที่เลือกไว้จะถูกใช้งานอย่างเข้มงวด: ถ้ามันไม่สามารถดําเนินการตามที่ร้องขอมาได้ GW GUI รายงาน การ จํากัด แทน ที่ จะ เปลี่ยน เครื่อง ยนต์ อย่าง เงียบ ๆ.

การเป็นเอกราชนี้เจตนา ตัว อย่าง เช่น การ อ่าน ร่าง กาย อาจ ใช้ Greaseweazle Host Tools ในขณะที่การแปลงภาพและการสํารวจ ใช้กลไกภายใน ตัวเลือกของเครื่องยนต์บันทึกในโพรไฟล์หรือโครงการ หมายเหตุเมื่อความเหลื่อมล้ําที่สําคัญ

### โพรไฟล์

<p align="center"><img src="images/options-profiles-en.png" alt="โพรไฟล์" width="72%"></p>

โพรไฟล์เก็บค่าต่าง ๆ ไว้สําหรับการอ่าน, เขียน และทําการแปลง เลือกหมวดหมู่ที่เกี่ยวข้องเพื่อจัดการโพรไฟล์ โพรไฟล์ที่เลือกไว้จะถูกแสดงในแถบสถานะลมหลักและในหน้าจอปฏิบัติการ

ใช้โพรไฟล์สําหรับการทํางานซ้ําได้ แทนการเก็บสะสมธงผู้เชี่ยวชาญ ให้ชื่อแต่ละโพรไฟล์ เช่น ไดรฟ์เฉพาะ, ครอบครัวดิสก์, หรือวิธีกู้คืน ทบทวนโพรไฟล์หลังจากการปรับปรุงเครื่องยนต์พื้นฐาน เนื่องจากตัวเลือกที่รองรับสามารถเปลี่ยนแปลงได้

## ตัวเลือกการจําลอง

เดอะ **จําลอง** ตัวเลือกต่าง ๆ มีการตั้งค่าการจัดเก็บทั่วไป, ปุ่มพิมพ์ลัดทั่วไป, บันทึกการปรับแต่งต่าง ๆ และการตั้งค่าการกําหนดค่าต่าง ๆ ของเครื่อง

### โฟลเดอร์การจําลองทั่วไป

<p align="center"><img src="images/options-emulation-general-en.png" alt="ตัวเลือกการจําลองทั่วไป" width="72%"></p>

ตั้งค่าโฟลเดอร์เก็บเอกสารร่วม และโฟลเดอร์ปริยายสําหรับจับภาพและบันทึกสถานะ **เปิดโฟลเดอร์** เปิดตําแหน่งที่ใช้ร่วมกันในการสํารวจแฟ้ม

เก็บจับและบันทึกรัฐไว้ในโฟลเดอร์แยก การจับภาพเป็นภาพทั่วไป; รัฐที่บันทึกไว้มีสถานะเครื่องจําลอง และอาจจะขึ้นอยู่กับรุ่นจําลองและการปรับแต่งที่สร้างมัน สํารองการปรับแต่งและสื่อ เคียงข้างรัฐที่สําคัญที่ถูกบันทึก

### ปุ่มพิมพ์ลัดส่วนรวม

<p align="center"><img src="images/options-emulation-shortcuts-en.png" alt="การจําลองปุ่มพิมพ์ลัด" width="72%"></p>

สืบค้นสําหรับการกระทําหรือกุญแจที่ได้รับมอบหมาย, กําหนดหรือลบปุ่มพิมพ์ลัด, เรียกคืนค่าปริยาย, และการขัดแย้งที่ชัดเจน คอลัมน์สถานะระบุการมอบหมายที่ถูกต้องและการขัดแย้ง

เพื่อเปลี่ยนปุ่มพิมพ์ลัด โปรดค้นหาการกระทํา แล้วคลิก **กําหนด ** และกดรหัสที่ต้องการ โปรดตรวจสอบสถานะก่อนจะทําการปิด **ล้างการขัดแย้ง ** ลบงานได้รับมอบหมายที่ขัดแย้งกัน; มันไม่ได้เรียกคืนการจับคู่ปริยาย ใช้ ** เรียกคืนค่าปริยาย** หากคุณต้องการแทนที่การมอบหมายกับชุดมาตรฐาน

### บันทึกการปรับแต่ง

<p align="center"><img src="images/options-emulation-configurations-en.png" alt="บันทึกการปรับแต่งการจําลอง" width="72%"></p>

หน้านี้รายการเครื่องบันทึก เลือกการปรับแต่งที่จะแก้ไขใน **Amiga** แท็บ คุณสามารถเรียกรายการใหม่อีกครั้ง หรือลบการปรับแต่งที่เลือกไว้

การลบการปรับแต่ง จะเป็นการลบนิยามเครื่องที่บันทึกไว้ออก ไม่ควรใช้เป็นวิธีปลดปล่อยสื่อ หรือปิดเครื่องทํางาน ก่อนทําการลบข้อมูล โปรดสังเกตว่า ROMแฟ้มภาพ และแฟ้มสถานะต่าง ๆ ที่สัมพันธ์กับการปรับแต่ง

## Amiga การปรับแต่ง

ส่วนติดต่อปัจจุบันให้รายละเอียด Amiga หน้าการปรับแต่ง โครง สร้าง เดียว กัน นี้ สามารถ ขยาย ต่อ ไป อีก สําหรับ ระบบ อื่น ๆ ที่ เลียน แบบ โดย ไม่ เปลี่ยน การ ไหล เวียน ของ งาน.

### ค่าทั่วไป

<p align="center"><img src="images/options-amiga-general-en.png" alt="Amiga ตั้งค่าทั่วไป" width="72%"></p>

เลือก Amiga รุ่น, บันทึกการปรับแต่ง, ติดตั้งหรือแทนที่รุ่นตัวจําลอง, และกําหนดโฟลเดอร์ปริยายสําหรับฮาร์ดดิสก์และสื่ออื่น ๆ **ค้นหารุ่น** ประมวลผลแหล่งกําเนิดการกลับหัวอย่างเป็นทางการ

เริ่มจากโมเดลเพราะมันบังคับหน้าต่อไป เปลี่ยนมันสามารถเปลี่ยนที่มีอยู่ CPUความทรงจํา ROMมันฝรั่งทอดและทางเลือกการจัดเก็บ หลังจากเลือกรุ่นของตัวจําลองแล้ว ให้บันทึกการปรับแต่งก่อนเรียกมันจากหน้าต่างหลัก การติดตั้งรุ่นตัวจําลองอื่น จะเป็นการแทนที่รุ่นที่ถูกใช้โดยการปรับแต่งนั้น ๆ มันไม่ได้สร้างสําเนาตัวที่สองของเครื่อง

### CPU

<p align="center"><img src="images/options-amiga-cpu-en.png" alt="Amiga CPU ตั้งค่า" width="72%"></p>

เดอะ CPU หน้าแสดงตัวประมวลผลที่เลือกโดยแบบจําลองเครื่องจักร และให้ความแม่นยําที่เข้ากันได้ FPUและตัวเลือกความเร็ว ตัวเลือกที่ไม่สามารถปรับใช้กับรุ่นที่เลือกไว้ได้

- **CPU รุ่น** แสดงตัวประมวลผลที่เลียนแบบได้
- **จํานวนทศนิยม** ควบคุมการจับเวลา โหมดการวนรอบ ชื่นชอบฮาร์ดแวร์ความเข้ากันได้ แต่ต้องประมวลผลเครื่องโฮสต์มากขึ้น
- **FPU** เปิดใช้การปรับจุดลอยที่เข้ากันได้เมื่อรองรับ
- **CPU ความเร็ว** เลือกการจับเวลาดั้งเดิมหรือโหมดเร่งความเร็ว

สําหรับการปรับแต่งพื้นฐาน ให้คงรุ่น- Devived CPU และความเร็วเดิม เปลี่ยนความเร่งเฉพาะหลังจากที่บูตเครื่องอย่างถูกต้องที่การตั้งค่ามาตรฐาน

### RAM

<p align="center"><img src="images/options-amiga-ram-en.png" alt="Amiga RAM ตั้งค่า" width="72%"></p>

ปรับแต่งชิป RAMช้าๆ RAMเร็ว RAMและสนับสนุนการขยายความทรงจํา ข้อความที่เข้ากันได้อธิบายข้อจํากัดสําหรับเครื่องที่เลือก และหน่วยความจําที่ปรับแต่งแล้วทั้งหมด แสดงอยู่ที่ด้านล่าง

**ชิป RAM ** จะเข้าถึงชิปที่กําหนดเอง และต้องใช้ในชานชาลา ** ช้า RAM ** แสดงถึงหน่วยความจําการขยายที่เข้ากันได้ที่ถูกใช้โดยการปรับแต่งทั่วไป ** เร็ว RAM ** เป็นหน่วยความจําการขยายของหน่วยประมวลผล ** Zorro ที่ 3 RAM** ใช้เฉพาะโมเดลที่สนับสนุนสถาปัตยกรรมที่ขยายตัว ข้อความที่เข้ากันได้และปิดการใช้งาน จะป้องกันไม่ให้มีการผสมกันซึ่งรุ่นที่เลือกไม่สามารถแทนได้

### ROM

<p align="center"><img src="images/options-amiga-rom-en.png" alt="Amiga ROM ตั้งค่า" width="72%"></p>

เลือกการเริ่มทํางานของระบบ ROMเพิ่ม ROMและ ROM กุญแจ การตรวจจับ--ROM รายการ ต่าง ๆ แสดง ชื่อ, แก้ไข ใหม่, และ เข้า กัน ได้ กับ รุ่น ที่ เลือก ไว้. เลือกที่ตรวจพบ ROM คลิก **ใช้** หรือเรียกดูแฟ้มด้วยตัวเอง

ROM แฟ้มที่ยังไม่ได้จัดให้ GW GUIใช้รอมได้ตามกฎหมาย

รายการที่ตรวจสอบสามารถคาดเดาได้จากชื่อแฟ้มได้: มันรายงาน ROM การแสดงตัวและแก้ไขและประเมินความเข้ากันได้กับรุ่นที่เลือกไว้ **ใช้ได้** เป็นทางเลือกที่ปกติ ** เข้ากันได้บางส่วน ** ระบุว่า ROM อาจจะบูต แต่ไม่ตรงกับเครื่อง ** รีเฟรช ** ตั้งค่าใหม่ ROM สถานที่ ** ใช้** มอบหมายการค้นหาที่เลือก ROM แด่การปรับแต่ง

### วิดีโอ

<p align="center"><img src="images/options-amiga-video-en.png" alt="Amiga ตั้งค่าวิดีโอ" width="72%"></p>

ปรับแต่งค่ามาตรฐานวิดีโอ, ค่าสัดส่วนด้านสัดส่วน, ความละเอียด, โหมดบรรทัด, ตัวแปลกรอบ, ความลึกสี, การข้ามเฟรม, แกมมา, และการแก้ไขแบบกระพริบ การตั้งค่า shiftet เพิ่มเติม จะอยู่ด้านล่างของหน้านี้ เมื่อถูกรองรับจากรุ่นที่เลือก

| ตั้งค่า | ลูกเล่นที่ใช้ได้ |
|---|---|
| มาตรฐานวิดีโอ | เลือก PAL หรือ NTSC เวลา และ ความ ประพฤติ ที่ คาด หมาย ว่า จะ สดชื่น |
| สัดส่วนภาพ | ควบคุมการปรับขนาดรูปภาพ |
| ความละเอียด | เลือกรายละเอียดของผลลัพธ์อัตโนมัติหรือโดยตรง |
| โหมดเส้น | ควบคุมการแสดงผลแบบข้อความหรือแบบบรรทัด |
| กรอบ | เอารายการออกเมื่อเปิดใช้งาน |
| การแสดงผล | เลือกแบ็คเอนต์เอกสารกราฟิก |
| ความลึกสี | เลือกความละเอียดสีผลลัพธ์ |
| ข้ามเฟรมภาพ | ย่อหน้าต่างหาย |
| แกมมา | ปรับค่าความสว่างของภาพ |
| เครื่องมือแก้ไข Flicker | โหมดโพรเซสที่จะกระพริบ |

เปลี่ยนการตั้งค่าการแสดงผลทีละตัว ถ้าหน้าต่างการจําลองกลายเป็นว่างหรือไม่มั่นคง ให้กลับไปแก้ไขอัตโนมัติ, ข้ามเฟรม, แกมมาที่เป็นกลาง, และตัวแปลงานก่อนหน้านี้

### เสียง

<p align="center"><img src="images/options-amiga-audio-en.png" alt="Amiga ตั้งค่าเสียง" width="72%"></p>

เปิดหรือปิดเสียง ให้เลือกอุปกรณ์ส่งออกเสียงและรุ่นหลัง จากนั้นปรับแต่งการแทรก Amiga กําลังกรอง, ประเภทตัวกรอง, การแยกสเตอริโอ, เสียงแผ่นฟลอปปี-ไดรฟ์ และปริมาตรซีดีออดิโอ

ความเครียดต่ําลดความล่าช้า แต่สามารถทําให้เครื่องตกได้ เพิ่มมันถ้าเสียงแตก ตํารวจสากลและ Amiga ตัวกรองเสียงเปลี่ยนแปลงการสืบพันธุ์ของเสียง แทนที่จะเปลี่ยนตรรกะของโปรแกรม ระดับเสียงไดรฟ์-เสียงควบคุมเสียงจําลองจากปกติ Amiga เสียง

### สื่อ

<p align="center"><img src="images/options-amiga-storage-en.png" alt="Amiga ตั้งค่าการจัดเก็บ" width="72%"></p>

หน้า เก็บ รายการ ตัว ระบุ อุปกรณ์, ประเภท, รุ่น, สื่อ ที่ เกี่ยว ข้อง, และ สิ่ง ต่าง ๆ ที่ มี อยู่. เพิ่ม, ปรับแต่ง, หรือลบอุปกรณ์ที่นี่ แผ่นฟลอปปี้และซีดี สามารถใส่หรือแทนที่ได้โดยตรงจากเครื่องที่กําลังทํางานอยู่

เดอะ **ตัวระบุอุปกรณ์** คือวิธีที่ระบบจําลองที่อยู่อุปกรณ์ ** ชนิด ** แยกแยะฟลอปปี้, ฮาร์ดดิสก์, แสง, และอุปกรณ์อื่น ๆ ที่รองรับ ** รุ่น ** อธิบายฮาร์ดแวร์เลียนแบบในขณะที่ ** สื่อที่สัมพันธ์กัน** ระบุรูปภาพที่ได้รับมอบหมายในปัจจุบัน ปรับแต่งอุปกรณ์ ก่อนที่จะทําการรวมสื่อชนิดเขียนได้ที่มีคุณค่า และคงการสํารองข้อมูลของสื่อที่มีฮาร์ดดิสก์ไว้

### แป้นพิมพ์

<p align="center"><img src="images/options-amiga-keyboard-en.png" alt="Amiga ตั้งค่าแป้นพิมพ์" width="72%"></p>

ค้นหา Amiga การกําหนดกุญแจและโฮสต์, การกําหนดกุญแจใหม่, การลบแผนที่, การเรียกคืนค่าปริยาย, หรือการขัดแย้งที่ชัดเจน คอลัมน์สถานะรายงานว่า การมอบหมายแต่ละรายการถูกต้องหรือไม่

คอลัมน์ด้านซ้ายชื่อที่คัดลอก Amiga กุญแจ **สังคม** แสดงปุ่มพิมพ์ลัดของโฮสต์ การจับคู่ที่ถูกต้องอาจจะยังไม่สะดวก ถ้าวินโดวส์หรือโปรแกรมสํารองปุ่มพิมพ์ลัดเดิมไว้ ดังนั้นทดสอบการจัดหมู่ที่สําคัญภายในเครื่อง หลีกเลี่ยงการกําหนดปุ่มพิมพ์ลัดที่แสดงบนจอภาพ หรือปุ่มพิมพ์ลัดเต็มจอ ให้เป็นกุญแจที่โปรแกรมที่เลียนแบบต้องการบ่อยๆ

### เมาส์

<p align="center"><img src="images/options-amiga-mouse-en.png" alt="Amiga ตั้งค่าเมาส์" width="72%"></p>

ตั้งค่าความเร็วของเมาส์ โดยเลือกว่าจะให้แท่งแอนาล็อกตัวใดควบคุมเมาส์, ปรับพื้นที่ตายและความเร็วที่คล้าย ๆ กัน และปรับแต่งการจับคู่การเคลื่อนเมาส์ เรียกคืนค่าปริยายหรือการขัดแย้งในการทําแผนที่ที่ชัดเจนเมื่อจําเป็น

เพิ่มเขตตาย ถ้าตัวควบคุมทําให้พอยท์เตอร์ลอย ปรับความเร็วแท่งซ้ายและขวาให้เป็นอิสระเมื่อเปิดใช้แท่งทั้งสอง ส่วนร่วมของตารางการจับคู่ตัวพิมพ์เล็ก โดยใช้ปุ่มหรือการกระทําของเมาส์ เป็นตัวแสดงสถานะขัดแย้ง หลังจากเปลี่ยนการโยงไปยังตัวควบคุมอื่นแล้ว

### ตัวควบคุม

<p align="center"><img src="images/options-amiga-controllers-en.png" alt="Amiga ตั้งค่าตัวควบคุม" width="72%"></p>

ตรวจจับตัวควบคุมการเชื่อมต่อ, มอบหมายอุปกรณ์และประเภทของตัวควบคุม Amiga พอร์ตต่าง ๆ และปรับแต่งการวางแผงควบคุม และการตั้งค่าการยิงเทอร์โบ ตัวเลือกที่มีอยู่ขึ้นอยู่กับฮาร์ดแวร์ที่ตรวจพบและเครื่องที่เลือก

พอร์ต 1 และพอร์ต 2 ได้รับการปรับแต่งเอง **อัตโนมัติ** ชนิดของตัวควบคุมเป็นจุดเริ่มต้นที่มีเหตุผล แต่ซอฟต์แวร์ที่คาดหวังว่า แท่งควบคุมหรือเมาส์โดยเฉพาะ อาจต้องการชนิดเฉพาะ ประมวลผลการตรวจพบก่อนที่จะกําหนดตัวควบคุมการเชื่อมต่อใหม่ ไฟไหม้เทอร์โบซ้ํา เปิดใช้งานค่าที่ป้อนเข้าแบบแผนที่ และควรจะปิดการใช้งานไว้ ยกเว้นเกมหรือโปรแกรมจะได้ประโยชน์จากมัน

## การ วินิจฉัย และ การ บํารุง รักษา ฮาร์ดแวร์

กล่องโต้ตอบเหล่านี้ถูกเปิดใช้จาก **เครื่องมือ ** แท็บ แสดงตัวอย่างแต่ละกล่องโต้ตอบที่ถูกสร้าง Greaseweazle คําสั่ง ทบทวนมันก่อนที่จะคลิก ** ประมวลผล**.

### ข้อมูลตัวควบคุม

<p align="center"><img src="images/tool-controller-information-en.png" alt="ข้อมูลตัวควบคุม" width="62%"></p>

แสดงข้อมูลของตัวควบคุมที่เลือก ขยาย **แสดงผล Raw** เมื่อคุณต้องการการตอบรับคําสั่งที่สมบูรณ์

ใช้นี่เป็นคําสั่งวินิจฉัยครั้งแรก การตอบสนองที่ประสบความสําเร็จยืนยันว่า GW GUI สามารถเริ่มโปรแกรมประมวลผลเครื่องมือของโฮสต์และสื่อสารกับอุปกรณ์ที่เลือกได้ บันทึกข้อมูลบริษัทและฮาร์ดแวร์ ก่อนที่จะทําการปรับปรุง

### USB แบนด์วิธ

<p align="center"><img src="images/tool-usb-bandwidth-en.png" alt="USB แบนด์วิธ" width="62%"></p>

วัดค่าที่ใช้ได้ USB วงจรสื่อสาร ใช้มันเพื่อวินิจฉัยการโอนแบบไม่เสถียรหรือไม่เหมาะสม USB เชื่อมโยง

ปิดโปรแกรมอื่น ๆ ด้วยตัวควบคุมก่อนการทดสอบ ทําซ้ําการวัดหลังจากที่เปลี่ยน USB พอร์ต, สายเคเบิล, หรือที่วาง การ เปรียบ เทียบ ผล ที่ เกิด ขึ้น ภาย ใต้ สภาพ การณ์ คล้าย ๆ กัน แทน ที่ จะ ทํา การ วัด เพียง ครั้ง เดียว เป็น การ รับ ประกัน อย่าง แน่นอน.

### ความเร็วในไดรฟ์

<p align="center"><img src="images/tool-drive-speed-en.png" alt="ความเร็วในไดรฟ์" width="62%"></p>

วัดความเร็วการหมุน เพิ่มจํานวนของการวัด เมื่อคุณต้องการผลตัวแทนมากขึ้น

การ วัด เพียง ครั้ง เดียว คือ การ ตรวจ สอบ อย่าง รวด เร็ว; การ วัด หลาย ครั้ง เผย ว่า ความ เร็ว คงที่ หรือ ไม่. ให้ ไดรฟ์ ไป ถึง ความ เร็ว ปกติ ก่อน จะ แปล ผล ที่ ได้. ค่า ที่ ไม่ คาด คิด อาจ บ่ง ชี้ ถึง ความ เร็ว ที่ กําหนด ไว้ ผิด, ปัญหา เรื่อง เครื่อง ยนต์, หรือ ปัญหา ใน การ ทํา การ วัด.

### ค้นหาหัว

<p align="center"><img src="images/tool-seek-head-en.png" alt="ค้นหาหัว" width="62%"></p>

ย้ายหัวไดรว์ไปยังกระบอกที่เลือกไว้ **อนุญาตให้ใช้กระบอกแบบสุดขั้ว ** อนุญาตตามปกติจํากัดตําแหน่งและ ** ให้มอเตอร์ทํางาน** ออกจากมอเตอร์ทํางานในระหว่างการดําเนินการ ใช้ตําแหน่งสุดขั้วเฉพาะเมื่อขั้นตอนฮาร์ดแวร์ โดยตรงที่ต้องการพวกเขา

การ แสวง หา แบบ ปกติ เป็น ประโยชน์ ต่อ การ ยืน ยัน การ เคลื่อน ไหว ของ ศีรษะ หรือ ตําแหน่ง ก่อน การ วินิจฉัย โรค. ฟังผลกระทบซ้ําผิดปกติและหยุดถ้ากระบอกร้องขอไม่เหมาะสมสําหรับไดรฟ์ เครื่องมือนี้ยังไม่ได้อ่านหรือตรวจความถูกต้องที่กระบอกปลายทาง

### วิเคราะห์การจัดตําแหน่งไดรฟ์

<p align="center"><img src="images/tool-drive-alignment-en.png" alt="วิเคราะห์การจัดตําแหน่งไดรฟ์" width="62%"></p>

Runs read สําหรับการวิเคราะห์ลักษณะการขับ มันรองรับการเลือกเพลง, การปฏิวัติและอ่านนับ, รูปแบบ decotting, flix, ดัชนี, ความเร็ว PLLหมุดความหนาแน่น TG43และกลับตาลปัตร งาน จัด ระเบียบ ต้อง มี สื่อ อ้างอิง และ ความ รู้ ด้าน อุปกรณ์ ที่ เหมาะ สม.

เริ่มด้วยดิสก์อ้างอิงที่รู้จัก และชุดที่น้อยที่สุดของตัวแทนที่ **จัดเรียงเพลง ** กําหนดเพลงและหัวตัวอย่าง; ** การปฏิวัติต่อแทร็ก ** ควบคุมระยะเวลาตัวอย่างแต่ละตัว ** จํานวนครั้งที่อ่าน** กําหนดการทําซ้ํา เปิดใช้การกําหนดค่าแผ่นเองหรือการถอดรหัสแผ่นเมื่อตรงกับสื่อที่อ้างถึงเท่านั้น ตัวเลือกต่าง ๆ เช่น ดัชนีปลอม ส่วนที่ยาก PLL การแทนที่, เข็มหมุดความหนาแน่น, และ TG43 เป็นฮาร์ดแวร์ หรือเป็นรูปแบบเฉพาะ และสามารถทําให้การเปรียบเทียบไม่เที่ยงตรงได้

### เข็มหมุดฮาร์ดแวร์

<p align="center"><img src="images/tool-hardware-pins-en.png" alt="เข็มหมุดฮาร์ดแวร์" width="62%"></p>

อ่านหรือเปลี่ยนแปลงเข็มควบคุมที่รองรับ เลือกเข็มหมุด, เปิด **เปลี่ยนเข็มหมุด ** เมื่อมีการเขียนค่าและเลือก ** สูง** เมื่อจําเป็นจากปฏิบัติการฮาร์ดแวร์

ด้วย **เปลี่ยนเข็มหมุด** ปิดการใช้งาน คําสั่งจะปรับเข็มหมุด นี่เป็นตัวเลือกที่ปลอดภัยกว่า เปลี่ยนระดับผลกระทบโดยตรงกับตัวควบคุม I/O และควรทําด้วยความถูกต้องเท่านั้น Greaseweazle เอกสารฮาร์ดแวร์และสายไฟ

### ตั้งค่าเครื่องมือควบคุมใหม่

<p align="center"><img src="images/tool-reset-controller-en.png" alt="ตั้งค่าเครื่องมือควบคุมใหม่" width="62%"></p>

ตั้งค่าใหม่ Greaseweazle ผู้ควบคุม ใช้นี่เมื่อตรวจจับตัวควบคุมได้แต่ไม่ตอบสนองตามปกติ

กําลังรอปฏิบัติการใด ๆ ในแผ่นดิสก์ที่ทํางานอยู่ เพื่อทําให้เสร็จก่อนทําการรีเซ็ต หลัง จาก นั้น ให้ ตรวจ สอบ ตัว ควบคุม อีก ครั้ง ถ้า สถานะ การ เชื่อม ต่อ ของ มัน ไม่ ได้ ฟื้น ตัว โดย อัตโนมัติ. การรีเซ็ตไม่ได้แก้ไขข้อผิดพลาด `gw.exe` เส้นทางหรือการเชื่อมต่อ USB อุปกรณ์

### หน่วงเวลา

<p align="center"><img src="images/tool-delays-en.png" alt="หน่วงเวลาตัวควบคุม" width="62%"></p>

อ่าน หรือ เปลี่ยน ค่า กําหนด เวลา รวม ทั้ง การ คัด เลือก, การ ทํา ตาม ขั้น ตอน ต่าง ๆ, การ ตั้ง หลัก การ, การ ใช้ มอเตอร์, การ ลด การ เลือก ตั้ง โดย อัตโนมัติ, การ เขียน เวลา, และ การ ทํา หน้ากาก ดัชนี ช้า ลง. เปิดใช้งานเฉพาะค่าที่คุณตั้งใจจะแก้ไขเท่านั้น

ช่องข้อมูลที่ไม่ได้ตรวจสอบ ทําให้ค่าตัวควบคุมที่สอดคล้องกันไม่เปลี่ยนแปลง ก่อนที่จะแก้ไข โปรดบันทึกค่าที่มีอยู่ การกําหนดการเปลี่ยนแปลง มีผลกระทบต่อทุกปฏิบัติการทางกายภาพที่ตามมา ดังนั้นการทดสอบกับสื่อที่ใช้ได้ และเรียกคืนค่านิยมที่ดีที่รู้จักกัน

### แม่ข่าย

<p align="center"><img src="images/tool-firmware-en.png" alt="การปรับปรุงเครื่องแม่ข่าย" width="62%"></p>

ปรับปรุงเครื่องควบคุม **ปรับปรุงโปรแกรมโหลดโหลดโหลดข้อมูล** มี การ ระบุ อย่าง ชัดเจน ว่า มี ความ เสี่ยง และ ควร รักษา ตัว ให้ อยู่ ใน สภาพ ที่ ไม่ สามารถ ทํา ได้ นอก เสีย จาก ว่า ขั้น ตอน ต่าง ๆ ของ บริษัท นั้น เรียก ร้อง. อย่าปลดเครื่องควบคุมระหว่างการปรับปรุง

ก่อนการปรับปรุง โปรดยืนยันตัวควบคุมการเชื่อมต่อด้วย **ข้อมูลตัวควบคุม** ใช้คอกม้า USB เชื่อมต่อ และปิดซอฟท์แวร์อื่น ที่สามารถเข้าถึงมัน หลังจากเสร็จสิ้น, การเชื่อมต่อใหม่หรือ rescan ตัวควบคุมและอ่านข้อมูลอีกครั้ง เพื่อตรวจสอบรุ่นของ บริษัท

## ประวัติการปฏิบัติการและปูมบันทึก

เปิดประวัติปฏิบัติการเพื่อตรวจสอบปูมบันทึกที่ถูกบันทึกโดยปฏิบัติการ

<p align="center"><img src="images/operation-history-en.png" alt="ประวัติการปฏิบัติการ" width="68%"></p>

เลือกปูมบันทึกด้านซ้ายเพื่อแสดงเนื้อหา **ส่งออก** บันทึกสําเนาสําหรับวิเคราะห์หรือรองรับ พาธและบรรทัดคําสั่งอาจมีชื่อโฟลเดอร์ส่วนตัวอยู่ ดังนั้น ทบทวนปูมบันทึกการส่งออกก่อนที่จะใช้ร่วมกัน

คอนโซลสดในหน้าต่างหลัก แสดงคําสั่งปัจจุบันและผลลัพธ์ล่าสุด ปุ่มคัดลอกของมันคัดลอกข้อความที่แสดงผล

### กําลังอ่านปูมบันทึก

บันทึกการตรวจสอบที่มีประโยชน์บรรจุคําสั่งที่สร้างขึ้น, เวลาประทับ, การแสดงผลของเครื่องยนต์และสถานะสุดท้าย ทํา งาน จาก ส่วน ล่าง ขึ้น ไป: ความ ล้ม เหลว ทั่ว ไป ใน ภาย หลัง มัก จะ เป็น เพียง ผล ของ ข้อ ความ ก่อน หน้า นั้น ที่ เจาะจง กว่า.

เมื่อ เปรียบ เทียบ การ พยายาม สอง ครั้ง ตรวจ สอบ ดู ว่า ตัว ควบคุม, ไดรฟ์, เครื่อง ยนต์, โปรไฟล์, แหล่ง ข้อมูล, รูป แบบ การ ออก เสียง, และ ข้อ โต้ แย้ง ของ ผู้ เชี่ยวชาญ นั้น เหมือน กัน. มิ ฉะนั้น ผล ที่ ต่าง กัน อาจ สะท้อน ให้ เห็น สภาพ การณ์ ที่ เปลี่ยน ไป แทน ที่ จะ เป็น ความ ไม่ มั่นคง ของดิสก์.

## ข้อมูลของโปรแกรมและการใช้แบบพกพา

GW GUI เก็บข้อมูลผู้ใช้แยกออกจากรายการโปรแกรม ขึ้นอยู่กับแพกเกจและโหมดที่เลือก, การตั้งค่า, ปูมบันทึก, เครื่องมือดาวน์โหลด, ส่วนประกอบตัวจําลอง, จับภาพ, รัฐ, และการปรับแต่งเครื่องต่าง ๆ จะถูกเก็บไว้ในโปรแกรม `Data` ไดเรกทอรีหรือในตําแหน่งที่ผู้ใช้กําหนด

ก่อนจะทําการแทนที่หรือย้ายการติดตั้งแบบพกพา ให้เก็บโฟลเดอร์โปรแกรมที่สมบูรณ์ไว้และสํารองข้อมูล `Data` โฟลเดอร์ ห้ามย้ายแฟ้มส่วนตัวจาก `lib`เพราะว่าโปรแกรมได้แก้ไข ห้องสมุดส่วนตัวและสามส่วนจากโครงสร้างนั้น

สํารอง ข้อ แนะ ต่อ ไป นี้ เมื่อ มี ความ สําคัญ ต่อ การ ไหล เวียน ของ คุณ:

- ตั้งค่าและโพรไฟล์ของโปรแกรม
- ตัวควบคุมและไดรฟ์นิยาม;
- การปรับแต่งการจําลอง
- ROM พาธและจัดขึ้นตามกฎหมาย ROM สํารอง
- ภาพยากและเปลี่ยนแปลงได้
- จับและช่วยชีวิตรัฐต่าง ๆ
- บันทึกปฏิบัติการที่ใช้เป็นบันทึกการเก็บรักษา

ภาพจากดิสก์อาจจะมีขนาดใหญ่กว่าการตั้งค่า ร้านค้าต้นแบบการอ่านเฉพาะเมื่อเป็นไปได้ และทํางานกับสําเนา

## การ ทํา งาน ที่ ได้ รับ คํา แนะ นํา

### กําลังรับข้อมูลแผ่นที่ไม่รู้จัก

1. ตรวจ และ ทํา ความ สะอาด ไดรฟ์ โดย ใช้ วิธี บํารุง รักษา ที่ เหมาะ สม.
2. ป้องกันดิสก์ด้วย ถ้าเป็นไปได้
3. เลือก **อ่าน > อิมเมจ Raw (SCP)**.
4. ใช้ชื่อแฟ้มและอ่านช่วงเพลงปกติที่มีการปฏิวัติหลายรูปแบบ
5. ทบทวนคอนโซลและบันทึกปูมบันทึก
6. จําแนกทั้งสองฝั่ง **การถ่ายภาพ**.
7. แปลงสําเนาเป็นรูปแบบเซกเตอร์
8. ทดสอบสําเนาที่ดัดแปลงแล้วใน **Disk Explorer** หรือซอฟท์แวร์ที่เหมาะสม
9. เก็บ รักษา ไว้ ให้ ดี.

### ซ่อมแซมดิสก์จากอิมเมจ

1. ตรวจ ดู รูป ปั้น และ ยืน ยัน ความ คาด หมาย ของ ครอบครัว และ รูป แบบ ของ ภาพ.
2. ใส่แผ่นที่ต้องใช้ได้หรือเขียนได้โดยเจตนา ขนาดและความหนาแน่นที่ถูกต้อง
3. เปิด **เขียน** และเลือกภาพ
4. ยืนยันการใช้งานไดรฟ์ที่ปรับแต่งไว้แล้ว
5. เขียนดิสก์
6. อ่านกลับไปที่ภาพการตรวจสอบแยก
7. เปรียบ เทียบ เนื้อหา ที่ ได้ รับ การ คัด ลอก และ ทบทวน ร่อง รอย ที่ น่า สงสัย.

### การ สร้าง แบบ จําลอง Amiga

1. เปิด **ตัวเลือกต่าง ๆ > จําลอง > การปรับแต่ง** และสร้างหรือเลือกเครื่องจักร
2. ใน **Amiga > ค่าทั่วไป** เลือกรุ่นและรุ่นจําลอง
3. กําหนด ให้ ได้ มา ซึ่ง ความ เข้า กัน ได้ ตาม กฎหมาย ROM.
4. คงรุ่นปริยายสําหรับ CPU ถึง RAM ในรองเท้าบูทแรก
5. ปรับแต่งวิดีโอและเสียงที่มีการตั้งค่าอัตโนมัติ
6. เพิ่มอุปกรณ์จัดเก็บและรวมภาพที่คัดลอกมาจากสื่อด้วย
7. คีย์บอร์ดรีวิว เมาส์ และตัวควบคุม
8. บันทึกการปรับแต่ง
9. กลับไปยัง **จําลอง ** เลือกแล้วคลิก **เปิด**.
10. หลังจากการบูตแบบพื้นฐานที่ประสบความสําเร็จเท่านั้น เปลี่ยนความเร่งหรือการตั้งค่าขั้นสูง

## ตรวจสอบความปลอดภัย

ก่อน **อ่าน**:

- ดิสก์ต้นทางอยู่ในไดรฟ์ที่ถูกต้อง
- แหล่งที่มาเป็นการเขียนป้องกันที่ที่เป็นไปได้;
- พาธของการแสดงผลจะไม่เขียนทับตัวหลักที่มีอยู่แล้ว
- โพรไฟล์และช่วงเพลงตรงกับดิสก์

ก่อน **เขียน ** หรือ ** ลบ**:

- ดิสก์ปลายทางอาจถูกทําลายได้
- ภาพและไดร์ฟที่ถูกต้อง
- ขนาดและความหนาแน่นของดิสก์เข้ากันได้
- ไม่ มี ผู้ เชี่ยวชาญ ทาง โบราณคดี คน ใด ถูก ใช้ เป็น จุด หมาย ปลาย ทาง.

ก่อนที่เครื่องมือเปลี่ยนฮาร์ดแวร์:

- ไม่มีปฏิบัติการอื่นทํางาน
- ตัวควบคุมที่ถูกต้องถูกเลือก
- ค่าปัจจุบันได้ถูกบันทึกไว้แล้ว
- ตัวควบคุมมีพลังที่เสถียร USB ความเชื่อมโยง
- การกระทําได้รับการสนับสนุนจากเอกสารฮาร์ดแวร์

## การยิงปัญหา

### ตัวควบคุมไม่ได้แสดงรายการ

1. เชื่อมต่อตัวควบคุมโดยตรงกับคอมพิวเตอร์
2. เปิด **ตัวเลือกต่าง ๆ > ตัวควบคุมและไดรฟ์**.
3. คลิก **ค้นหา**.
4. ตรวจสอบสถานะตัวควบคุมและความเร็ว
5. ทํางาน **ข้อมูลตัวควบคุม** ถ้าการตรวจสอบสําเร็จ แต่คําสั่งล้มเหลว

ถ้า ยัง ไม่ ปรากฏ ให้ ลอง ใช้ อีก ทาง หนึ่ง โดย ตรง USB พอร์ตและเคเบิล จากนั้นเรสแคน โปรดตรวจสอบตัวจัดการอุปกรณ์วินโดวส์ สําหรับอุปกรณ์อนุกรมที่ตรวจพบใหม่ ตัวควบคุมที่มองเห็นได้ไปยังวินโดวส์ แต่ไม่ได้อยู่กับ GW GUI ตามปกติแล้ว จะชี้ไปยังพอร์ตที่ไม่ว่าง, การปรับแต่งแบบย่อ, หรือปัญหาเครื่องมือของโฮสต์; ตัวควบคุมที่ไม่อยู่จากหน้าต่างไปยัง USBไฟฟ้า คนขับ หรือฮาร์ดแวร์

### `gw.exe` ไม่พบ

เปิด **ตัวเลือกต่าง ๆ > ตัวควบคุมและไดรฟ์** แล้วใช้ **ค้นหา gw.exe **, ** เลือก **หรือ ** ดาวน์โหลดรุ่นล่าสุด**ยืนยันว่าเส้นทางตรวจสอบชี้ไปที่วัตถุประสงค์ Greaseweazle การติดตั้ง

หลังจากเลือกแล้ว วิ่ง **ข้อมูลตัวควบคุม** สืบค้นปูมบันทึกสําหรับพาธที่ประมวลผลได้, แฟ้มสูญหาย, หรือรุ่นที่ไม่สามารถเริ่มการทํางานได้

### ปฏิบัติการที่ใช้เครื่องยนต์ผิด

เปิด **ตัวเลือกต่าง ๆ > เครื่องยนต์** และตรวจสอบเครื่องยนต์ที่ได้รับมอบหมายในการดําเนินงานที่แน่นอนที่ GW GUI ไม่ ถอย กลับ ไป ยัง เครื่อง อื่น.

ตั้งค่ากลไกแยก: การเปลี่ยนกลไกการแปลงไม่เปลี่ยนการอ่าน, การเขียน, หรือ Disk Explorer. เปิดปฏิบัติการที่ล้มเหลวอีกครั้ง หลังจากบันทึกตัวเลือกแล้ว และยืนยันคําสั่งที่สร้างในคอนโซล

### ไม่สามารถจัดการอิมเมจได้

ปิดการใช้งานการตรวจสอบอัตโนมัติ หากคุณรู้ค่าเครื่องจักรและรูปแบบที่ถูกต้องเท่านั้น ไม่อย่างนั้น ลอง **การถ่ายภาพ** แท็บเพื่อตรวจภาพในระดับต่ํา

ตรวจสอบว่าแหล่งกําเนิดคือตัวดักจับฟลักซ์ดิบ, ภาพภาค, กล่องบีบอัด, หรือแฟ้มที่ไม่เกี่ยวกัน โดยมีการสลับนามสกุล ไม่ต้องเปลี่ยนชื่อนามสกุลเพียงเพื่อบังคับการตรวจสอบ การแปลงจะต้องแปลโครงสร้างต้นฉบับอย่างถูกต้อง

### การจําลองยังไม่เริ่ม

ตรวจสอบการปรับแต่งที่ถูกบันทึก, รุ่นตัวจําลองที่ติดตั้งไว้, ที่เลือกไว้ ROMทางเดินเก็บของ และความเข้ากันได้ของโมเดล ทบทวนปูมบันทึกของโปรแกรมสําหรับรายละเอียดข้อผิดพลาดที่สมบูรณ์

ผลตอบแทนชั่วคราว CPU, RAMวีดีโอ และจัดเก็บลงในพื้นฐานที่เข้ากันได้อย่างง่าย หาก เส้น ฐาน เริ่ม ต้น แล้ว จง คืน ค่า ที่ กําหนด ไว้ ที ละ ตัว. การบันทึกรัฐที่สร้างขึ้นด้วยรุ่นจําลองอื่น หรือนิยามเครื่องจักรอาจจะล้มเหลวแม้เมื่อบูตที่สะอาด

### ปุ่มพิมพ์ลัดหรือค่านําเข้าใช้ไม่ได้

ตรวจสอบทั่วโลก **จําลอง > ปุ่มพิมพ์ลัด** หน้าและแป้นพิมพ์ระบุเครื่องจักร เมาส์ หรือหน้าควบคุม รับช่วงภารกิจใดๆ ที่ถือว่าเป็นการขัดแย้ง

หากจับเมาส์ได้ ให้ใช้ปุ่มพิมพ์ลัดปล่อยที่แสดงบนแถบเครื่องมือที่ทํางานอยู่ หากตัวควบคุมเชื่อมต่ออยู่ หลังจากเปิดตัวเลือกแล้ว ให้เรียกตรวจสอบตัวควบคุมอีกครั้ง ก่อนที่จะกําหนดมัน

### คําสั่งล้มเหลวอย่างไม่คาดคิด

1. อ่านการแสดงผลของคอนโซลแบบสดๆ
2. เปิด **ประวัติการปฏิบัติการ** สําหรับบันทึกที่สมบูรณ์
3. ยืนยันตัวควบคุมที่เลือก, ไดรฟ์, โพรไฟล์, เครื่องยนต์, และพาธของแฟ้ม
4. ส่งออกปูมบันทึกที่เกี่ยวข้อง หากต้องการใช้ร่วมกันสําหรับการวินิจฉัย

### เสียง แตก หรือ หยุด พัก

เพิ่มความหน่วงเสียง, ปิด CPU- แอพพลิเคชั่นที่เข้มงวด และคืนเฟรมวิดีโอข้ามและเร่งให้เข้ากับค่าก่อนหน้า ตรวจสอบว่าได้เลือกอุปกรณ์เสียงแบบวินโดวส์ที่กําหนดให้ใช้ จง เปลี่ยน ฉาก เหตุ การณ์ ใน แต่ ละ ครั้ง ดัง นั้น การ แก้ไข ที่ มี ประสิทธิภาพ จึง เป็น การ แก้ไข.

### ส่วนแสดงผลจําลองว่างหรือช้า

คืนค่าความละเอียดและโหมดบรรทัดไปยัง **อัตโนมัติ** ปิดการใช้งานการข้ามเฟรมและริบหรี่แก้ไขชั่วคราวและลองตัวแปลที่ทํางานก่อนหน้านี้ ยืนยันการตั้งค่า ROM และใส่สื่อบูตได้ถูกต้อง เดอะ FPS ตัวชี้วัดช่วยแยกแยะปัญหาการแปลงาน จากเครื่องจักรที่ไม่ได้บูต

### การอ่านมีร่องไม่เสถียร

อ่านซ้ําอีกครั้งเป็นชื่อแฟ้มใหม่ เพิ่มการปฏิวัติตามที่เหมาะสม และเปรียบเทียบร่องผลกระทบ ล้างหัวไดรฟ์โดยใช้ขั้นตอนที่ถูกต้อง และตรวจสอบดิสก์สําหรับความเสียหายทางกายภาพ อย่า อ่าน ซ้ํา แล้ว ซ้ํา เล่า เกี่ยว กับ การ หลั่ง ไหล หรือ ความ เสีย หาย ของ สื่อ ต่าง ๆ เพราะ การ ผ่าน ไป อีก อาจ ยิ่ง แย่ ลง.
