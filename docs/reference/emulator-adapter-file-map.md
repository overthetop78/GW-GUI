# Carte des fichiers des adaptateurs d’émulateurs

Cette carte consigne le propriétaire et le chemin final après réorganisation. Les fichiers sous `Common/` forment la prise interne identique de chaque famille. Les autres catégories à la racine appartiennent à la gestion commune de la famille. Tout code propre à un cœur se trouve sous `Emulators/<nom-du-cœur>/`, avec un espace de noms identique à son chemin. `GWGUI.Emulation` ne communique jamais directement avec ces dossiers de cœur.
