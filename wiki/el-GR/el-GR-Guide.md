# GW GUI Οδηγός χρήστη

GW GUI είναι μια εφαρμογή Windows για την ανάγνωση, γραφή, μετατροπή, επιθεώρηση, και την προσομοίωση των εικόνων δισκέτα-δίσκο. Μπορεί να ελέγξει. Greaseweazle υλικό, εργασία με αρχεία εικόνας δίσκων μέσω της εσωτερικής μηχανής του, και εκτελέστε αποθηκευμένες διαμορφώσεις μηχανής.

Αυτός ο οδηγός περιγράφει την αγγλική διεπαφή που εμφανίζεται στην τρέχουσα έκδοση της εφαρμογής. Γράφεται ως η πηγή του εκτυπώσιμου εγχειριδίου χρήστη: screenshots απεικονίζουν τα χειριστήρια, ενώ το περιβάλλον κείμενο εξηγεί τι να επιλέξετε, γιατί να το επιλέξετε, και πώς να επαληθεύσετε το αποτέλεσμα.

> **Σημαντικό:** Η ανάγνωση ενός δίσκου δεν είναι καταστροφική. Εγγραφή, διαγραφή, ενημέρωση firmware, και μερικά εργαλεία υλικού μπορούν να τροποποιήσουν τα μέσα ή το υλικό. Διαβάστε την προειδοποίηση που επισυνάπτεται στη σχετική διαδικασία πριν κάνετε κλικ ** Εκτέλεση**.

### Πώς να χρησιμοποιήσετε αυτόν τον οδηγό

Εάν αυτή είναι η πρώτη φορά που χρησιμοποιείτε GW GUI, πλήρης [Ξεκινώντας](#getting-started), στη συνέχεια ακολουθήστε [Διαβάζοντας ένα δίσκο](#reading-a-disk). Αν η εφαρμογή έχει ήδη ρυθμιστεί, πηγαίνετε απευθείας στο κεφάλαιο για τη λειτουργία που θέλετε να εκτελέσετε. Τα κεφάλαια επιλογών χρησιμεύουν ως αναφορά όταν μια διαδικασία σας ζητά να αλλάξετε μια κίνηση, μηχανή, προφίλ, ή εικονιζόμενη ρύθμιση μηχανών.

Τα ονόματα διεπαφής εμφανίζονται σε **έντονη**. Τα ονόματα αρχείων, οι διαδρομές, οι εντολές και οι κυριολεκτικές τιμές εμφανίζονται ως `code`. Σημειώσεις εξηγούν τη φυσιολογική συμπεριφορά? προειδοποιήσεις προσδιορίζουν τις λειτουργίες που μπορεί να μεταβάλλουν ένα δίσκο, ελεγκτή, ή αποθηκευμένες ρυθμίσεις.

## Κατανόηση της ροής εργασίας

GW GUI διαχωρίζει τις λειτουργίες φυσικού δίσκου από τις εργασίες αρχείου εικόνας:

| Στόχος | Εισαγωγή | Έξοδος | Προτεινόμενη σελίδα |
|---|---|---|---|
| Διατήρηση δισκέτας | Φυσικός δίσκος | Αρχείο εικόνας | **Ανάγνωση** |
| Επαναδημιουργία μιας δισκέτας | Αρχείο εικόνας | Φυσικός δίσκος | **Εγγραφή** |
| Τροποποίηση μορφής εικόνας | Αρχείο εικόνας | Ένα ή περισσότερα αρχεία εικόνας | **Μετατροπή** |
| Επιθεώρηση κομματιών και ανωμαλιών | Αρχείο εικόνας | Οπτική ανάλυση | **Οπτικοποίηση** |
| Περιήγηση αρχείων αποθηκευμένων σε μια εικόνα | Υποστηριγμένο σύστημα εικόνας/αρχείου | Αρχεία και κατάλογοι | **Disk Explorer** |
| Διάγνωση μιας κίνησης ή ελεγκτή | Greaseweazle υλικό | Μετρήσεις ή κατάσταση | **Εργαλεία** |
| Εκτέλεση μιας αποθηκευμένης εικονικής μηχανής | Αποθηκευμένες ρυθμίσεις μηχανών | Συνεδρία εξομοίωσης | **Εξομοίωση** |

Για διατήρηση, πρώτα κάνε μια ωμή σύλληψη και κράτα την αμετάβλητη ως αφέντη. Δημιουργήστε μετασχηματισμένα ή επισκευασμένα αντίγραφα εργασίας από αυτόν τον πλοίαρχο. Αυτό αποφεύγει την επανάληψη μιας φυσικής ανάγνωσης και διαφυλάσσει πληροφορίες που ένα τομεακό σχήμα δεν μπορεί να διατηρήσει.

## Έναρξη

### Απαιτήσεις

- Παράθυρα με το Microsoft .NET Χρόνος λειτουργίας επιφάνειας εργασίας που απαιτείται από την εφαρμογή.
- Α Greaseweazle ελεγκτής για φυσικές λειτουργίες δισκέτας-δίσκου.
- Μια καθορισμένη διαδρομή προς `gw.exe` όταν χρησιμοποιείτε το Greaseweazle Host Tools Μηχανή.
- Από νομική άποψη ROM αρχεία όταν τα απαιτεί μια μηχανή προσομοίωσης.

Η εφαρμογή ελέγχει την απαιτούμενη ώρα λειτουργίας του .NET κατά την εκκίνηση. Εάν λείπει, ακολουθήστε την προτροπή εγκατάστασης, στη συνέχεια επανεκκινήστε GW GUI.

### Πριν από τη σύνδεση υλικού

Ελέγξτε τα ακόλουθα πριν εκτελέσετε μια λειτουργία φυσικού δίσκου:

1. Σύνδεση Greaseweazle ελεγκτής σε σταθερό USB θύρα.
2. Συνδέστε το καλώδιο δισκέτας με το σωστό προσανατολισμό.
3. Συνδέστε το τροφοδοτικό κίνησης πριν εισάγετε πολύτιμα μέσα.
4. Επιβεβαιώστε ότι το μέγεθος και η πυκνότητα της κίνησης ταιριάζουν με το δίσκο.
5. Εγγραφή-προστατέψτε το δίσκο πηγή όταν είναι δυνατόν.

GW GUI δεν μπορούν να αποτρέψουν ζημιές που προκαλούνται από λανθασμένη καλωδίωση, ακατάλληλη ισχύ ή μηχανικά μη ασφαλή οδήγηση. Δοκιμάστε το άγνωστο υλικό με ένα αναλώσιμο δίσκο πρώτα.

### Πρώτη εκτόξευση

1. Άνοιγμα `gwgui.exe`.
2. Άνοιγμα **Επιλογές**.
3. Μέσα **Χειριστές και οδηγοί**, σαρώστε για το χειριστήριο και ρυθμίστε την κίνηση.
4. Επαλήθευση ή επιλογή της διαδρομής `gw.exe`.
5. Μέσα **Κινητήρες**, επιλέξτε ποιος κινητήρας θα πρέπει να εκτελέσει κάθε λειτουργία.
6. Επιστρέψτε στο κύριο παράθυρο και επιλέξτε την απαιτούμενη καρτέλα λειτουργίας.

### Επιβεβαίωση ότι η ρύθμιση είναι έτοιμη

Μια ρύθμιση εργασίας θα πρέπει να δείξει τον ελεγκτή και την οδήγηση στη γραμμή κατάστασης, για παράδειγμα έναν αριθμό κίνησης, το μέγεθος, την πυκνότητα, και COM θύρα. Μέσα **Επιλογές > Χειριστές και οδηγοί **, ο ελεγκτής θα πρέπει να φέρει σήμανση ** Διαθέσιμο ** και ο δίσκος ** Configure **Τρέξε. ** Πληροφορίες ελεγκτή** πριν από την ανάγνωση πολύτιμων μέσων, αν θέλετε να επαληθεύσετε την επικοινωνία χωρίς να αλλάξετε ένα δίσκο.

### Επιλογή μηχανής

GW GUI μπορούν να εκθέσουν περισσότερες από μία υλοποιήσεις για ορισμένες επιχειρήσεις. Η **Greaseweazle Host Tools** μηχανή επικαλείται το ρυθμισμένο `gw.exe`· το εσωτερικό GW GUI χειρολαβές κινητήρα που υποστηρίζονται λειτουργίες στο εσωτερικό της εφαρμογής. Η επιλογή του κινητήρα είναι σαφής και ανεξάρτητη για ανάγνωση, γραφή, μετατροπή, και Disk Explorer. Εάν μια λειτουργία δεν υποστηρίζεται από τον επιλεγμένο κινητήρα, GW GUI αναφέρει ότι η κατάσταση αντί να αλλάζει αυτόματα τους κινητήρες.

## Κύριο παράθυρο

Το κύριο παράθυρο ομαδοποιεί τις κύριες λειτουργίες σε επτά καρτέλες:

- **Ανάγνωση** δημιουργεί μια εικόνα από ένα φυσικό δίσκο.
- **Εγγραφή** γράφει μια εικόνα σε ένα φυσικό δίσκο.
- **Μετατροπή** μετατρέπει μια μορφή εικόνας δίσκου σε μία ή περισσότερες μορφές εξόδου.
- **Οπτικοποίηση** εμφανίζει κομμάτια και ροή ή αποκωδικοποιημένα δεδομένα.
- **Disk Explorer** περιηγείται υποστηριζόμενα συστήματα αρχείων και περιεχόμενα δίσκων.
- **Εργαλεία** παρέχει συντήρηση υλικού και διαγνωστικές εντολές.
- **Εξομοίωση** διαχειρίζεται και τρέχει αποθηκευμένες μιμούμενες μηχανές.

Η κονσόλα στο κάτω μέρος εμφανίζει την εντολή που εκτελείται και την έξοδο της. Η γραμμή κατάστασης αναφέρει την επιλεγμένη κίνηση, προφίλ και τρέχουσα κατάσταση.

### Ανάγνωση της διασύνδεσης

Οι περισσότερες σελίδες λειτουργίας ακολουθούν το ίδιο μοτίβο:

1. **Πηγή ή προορισμός** τα χειριστήρια προσδιορίζουν το δίσκο, την εικόνα ή το φάκελο.
2. **Έλεγχος μορφής** Επιλογή αυτόματης ανίχνευσης ή ρητής μηχανής και μορφής.
3. **Έλεγχος προφίλ** εφαρμογή επαναχρησιμοποιήσιμων ρυθμίσεων.
4. **Προχωρημένες ρυθμίσεις** εκθέτει παραμέτρους που είναι συνήθως προαιρετικές.
5. **Εκτέλεση** ξεκινά την επιχείρηση.
6. Η **κονσόλα** δείχνει την παραγόμενη εντολή, πρόοδο, προειδοποιήσεις και λάθη.

Η **Εκτέλεση** το κουμπί δεν υπονοεί ότι όλες οι τιμές είναι ασφαλείς για τον εισαγόμενο δίσκο. Ανασκοπήστε πάντα τον προορισμό και την επιλεγμένη κίνηση πριν από μια εργασία εγγραφής ή συντήρησης.

### Γραμμή κατάστασης και κονσόλα

Η αριστερή πλευρά της γραμμής κατάστασης προσδιορίζει την ενεργό φυσική κίνηση. Το κέντρο εμφανίζει το ενεργό προφίλ όταν επιλέγεται. Ο δείκτης κατάστασης αναφέρει αν η εφαρμογή είναι έτοιμη ή απασχολημένη. Η κονσόλα δεν είναι απλώς διαγνωστική: είναι η έγκυρη εγγραφή της εντολής που αποστέλλεται στον επιλεγμένο κινητήρα. Χρησιμοποιήστε τον έλεγχο αντιγράφων του όταν χρειάζεται να διατηρήσετε ή να μοιραστείτε αυτή την εντολή.

## Ανάγνωση δίσκου

Ανοίξτε το **Ανάγνωση** καρτέλα για να συλλάβει μια φυσική δισκέτα ως εικόνα.

<p align="center"><img src="../images/main-read-en.png" alt="Ανάγνωση καρτέλας" width="78%"></p>

### Βασική διαδικασία

1. Εισάγετε το δίσκο πηγής στη ρυθμισμένη κίνηση.
2. Επιλέξτε τον τύπο εικόνας:
   - **Πρώτη εικόνα (SCP)** διατηρεί πληροφορίες σε επίπεδο ροής.
   - **Γνωστή μορφή δίσκου** δημιουργεί μια εικόνα χρησιμοποιώντας μια επιλεγμένη μηχανή και μορφή.
3. Επιλέξτε το φάκελο προορισμού.
4. Εισάγετε το όνομα αρχείου εξόδου.
5. Επιλέξτε ένα προφίλ αν απαιτείται.
6. Κλικ **Εκτέλεση**.

Η κονσόλα δείχνει την ακριβή εντολή και πρόοδο. Μην αφαιρέσετε το δίσκο ή αποσυνδέσετε το χειριστήριο μέχρι να ολοκληρωθεί η λειτουργία.

### Επιλογή του τύπου εξόδου

Χρήση **Πρώτη εικόνα (SCP)** όταν ο στόχος είναι αρχειακή σύλληψη, ανάλυση, ανάκτηση ή μεταγενέστερη μετατροπή. Μια ακατέργαστη εικόνα καταγράφει πληροφορίες χρονισμού και πολλαπλές επαναστάσεις, η οποία είναι χρήσιμη για ασυνήθιστες μορφές, αδύναμους τομείς, συστήματα προστασίας, και κατεστραμμένα μέσα ενημέρωσης.

Χρήση **Γνωστή μορφή δίσκου** όταν ήδη γνωρίζετε την οικογένεια δίσκων και χρειάζεστε μια άμεσα χρήσιμη εικόνα τομέα. Αυτή η επιλογή μπορεί να είναι μικρότερη και ευκολότερη να ανοίξει σε άλλο λογισμικό, αλλά αντιπροσωπεύει το αποκωδικοποιημένο αποτέλεσμα και όχι κάθε λεπτομέρεια που παρατηρείται από την κίνηση.

Όταν είναι αβέβαιο, δημιουργήστε πρώτα την ωμή εικόνα. Μπορείτε να το μετατρέψετε αργότερα χωρίς να διαβάσετε το δίσκο και πάλι.

### Φάκελος, όνομα αρχείου και προφίλ

Η **Φάκελος ** είναι ο κατάλογος προορισμού. Η ** Όνομα αρχείου** θα πρέπει να προσδιορίζει το δίσκο χωρίς να βασίζεται μόνο στη φυσική ετικέτα του. Ένα χρήσιμο αρχειακό όνομα περιέχει τον τίτλο, τον αριθμό δίσκου ή την πλευρά, και μια σημείωση κατάστασης όταν ισχύει. Μην προσθέσετε μια επέκταση μορφής που έρχεται σε αντίθεση με την επιλεγμένη μορφή εξόδου.

Α **Προφίλ ** εφαρμόζει ένα αποθηκευμένο σύνολο αναγνωσμένων παραμέτρων. Επιλέξτε ένα μόνο όταν γνωρίζετε τι περιέχει. Η ** Προκαθορισμένο** Το προφίλ είναι κατάλληλο για μια κανονική πρώτη προσπάθεια· ένα εξειδικευμένο προφίλ ανάκτησης μπορεί σκόπιμα να διαβάσει περισσότερες στροφές ή διαφορετικό εύρος τροχιάς και συνεπώς να διαρκέσει περισσότερο.

### Προχωρημένες ρυθμίσεις

Επέκταση **Προχωρημένες ρυθμίσεις** στις παραμέτρους που αφορούν το μορφότυπο πρόσβασης ή τους εμπειρογνώμονες. Αφήστε αυτές τις τιμές αμετάβλητες, εκτός αν ο δίσκος απαιτεί ένα συγκεκριμένο εύρος τροχιάς, τον αριθμό επανάστασης, ή την επιλογή ελεγκτή.

Οι κοινές προηγμένες τιμές περιλαμβάνουν:

| Setting | Αντικείμενο | Πότε να το αλλάξετε |
|---|---|---|
| Εύρος κομματιού | Περιορίζει τους κυλίνδρους και τις κεφαλές για ανάγνωση | Μονόπλευρα μέσα, ασυνήθιστη γεωμετρία ή στοχευμένη κάρτα ανάκτησης |
| Επαναστάσεις | Έλεγχοι πόσες εναλλαγές λαμβάνονται υπόψη | Αύξηση για ασταθείς ή προστατευόμενες τροχιές· μείωση μόνο για ταχύτητα όταν απαιτείται |
| Επιχειρήματα εμπειρογνωμόνων | Περνάει πρόσθετες παραμέτρους κινητήρα | Μόνο όταν ακολουθεί τεκμηριωμένο Greaseweazle καθοδήγηση |

### Επαλήθευση επιτυχούς ανάγνωσης

Μην βασίζεστε μόνο στην απουσία διαλόγου σφάλματος. Μετά την ολοκλήρωση της εντολής:

1. Επιβεβαίωση ότι το αρχείο εξόδου υπάρχει και δεν είναι κενό.
2. Διαβάστε τις τελικές γραμμές κονσόλας για αποτυχημένα ή χαμένα κομμάτια.
3. Άνοιγμα της εικόνας **Οπτικοποίηση** να ελέγξει ότι και οι δύο πλευρές και το αναμενόμενο εύρος τροχιάς περιέχουν δεδομένα.
4. Άνοιξέ το. **Disk Explorer** όταν υποστηρίζεται το σύστημα αρχείων.
5. Κρατήστε το αρχείο καταγραφής λειτουργίας με σημαντικές αρχειακές συλλήψεις.

Αν οι επανειλημμένες αναγνώσεις διαφέρουν, διατηρήστε κάθε ακατέργαστη σύλληψη αντί να αναπληρώσετε την πρώτη. Οι διαφορές μπορεί να είναι χρήσιμες κατά την ανάκτηση.

## Εγγραφή δίσκου

Ανοίξτε το **Εγγραφή** καρτέλα για να γράψετε μια υπάρχουσα εικόνα σε μια φυσική δισκέτα.

<p align="center"><img src="../images/main-write-en.png" alt="Εγγραφή καρτέλας" width="78%"></p>

### Βασική διαδικασία

1. Εισάγετε το δίσκο προορισμού.
2. Επιλέξτε την εικόνα πηγής με **Περιήγηση**.
3. Επιβεβαιώστε την ανιχνευμένη μορφή.
4. Επιλέξτε ένα προφίλ αν απαιτείται.
5. Κλικ **Εκτέλεση**.

Η εγγραφή αντικαθιστά τα δεδομένα στο δίσκο προορισμού. Επαλήθευση της επιλεγμένης κίνησης και εικόνας πριν την εκκίνηση.

> **Προειδοποίηση:** Το γράψιμο είναι καταστροφικό. Αντικαθιστά τα μαγνητικά δεδομένα στο δίσκο προορισμού. Χρησιμοποιήστε ένα αρχείο πηγής που προστατεύεται με εγγραφή και ένα ξεχωριστό δίσκο προορισμού όποτε είναι δυνατόν.

### Πριν από την εγγραφή

Ελέγξτε τέσσερα αντικείμενα πριν κάνετε κλικ **Εκτέλεση**:

1. **Εικόνα:** η επιλεγμένη διαδρομή είναι η προβλεπόμενη εικόνα πηγής.
2. **Δίσκος:** ο δίσκος στο δίσκο μπορεί να αντικατασταθεί με ασφάλεια.
3. **Οδήγα:** το διαμορφωμένο μέγεθος και πυκνότητα ταιριάζουν στο μέσο προορισμού.
4. **Μορφή:** η αυτόματη ανίχνευση ή η χειροκίνητη επιλεγμένη μορφή ταιριάζει με την εικόνα.

Εάν η εικόνα πηγής δεν έχει δοκιμαστεί, ανοίξτε την **Οπτικοποίηση ** ή ** Disk Explorer** Πρώτα. Μια επιτυχημένη εγγραφή δεν μπορεί να επισκευάσει μια ελλιπή εικόνα πηγής.

### Επιθεώρηση τροχιάς και τροποποίηση

Αφού επιλεγεί μια εικόνα, **Ορατότητα κομματιών ** Ανοίγει την αναπαράσταση του κομματιού του. ** Τροποποίηση** εκθέτει τις υποστηριζόμενες τροποποιήσεις εικόνας πριν από τη γραφή. Οι διαθέσιμες ενέργειες εξαρτώνται από την επιλεγμένη μορφή και τη μηχανή.

### Επαλήθευση ενός γραπτού δίσκου

Όταν ο κινητήρας υποστηρίζει την επαλήθευση, χρησιμοποιήστε την για σημαντικά μέσα. Διαφορετικά, διαβάστε το γραπτό δίσκο πίσω σε μια νέα εικόνα και συγκρίνετε αποκωδικοποιημένα περιεχόμενά της ή επιθεωρήστε το σε **Οπτικοποίηση**. Κρατήστε τη σύλληψη επαλήθευσης χωριστά από την αρχική εικόνα έτσι ώστε το πρωτότυπο να μην αντικατασταθεί ποτέ.

Εάν η εγγραφή αποτύχει σε συνεπή κομμάτια, ελέγξτε την κατάσταση του δίσκου, την πυκνότητα, την καθαριότητα κίνησης, και τη διαμόρφωση κίνησης. Εάν οι αστοχίες συμβαίνουν τυχαία, ελέγξτε USB τη σταθερότητα και την επικοινωνία του ελεγκτή.

## Μετατροπή εικόνων δίσκων

Η **Μετατροπή** καρτέλα μετατρέπει μια εικόνα πηγής σε μία ή περισσότερες μορφές προορισμού.

<p align="center"><img src="../images/main-conversion-en.png" alt="καρτέλα μετατροπής" width="78%"></p>

### Βασική διαδικασία

1. Επιλέξτε την εικόνα πηγής.
2. Προαιρετικά παρέχει ονόματα εξόδου.
3. Διάλεξε μια οικογένεια μηχανών.
4. Επιλέξτε μία ή περισσότερες μορφές εξόδου και επεκτάσεις.
5. Ενεργοποίηση **Προσθήκη ετικετών** αν τα ονόματα αρχείων πρέπει να χρησιμοποιούν το ρυθμισμένο μοτίβο ετικέτας.
6. Κλικ **Εκτέλεση**.

Η **Επιλεγμένα ** ο πίνακας παραθέτει τις ζητούμενες εξόδους. ** Μετανάστες αρχείων** παρέχει την ειδική ροή εργασίας για τη μετανάστευση υποστηριζόμενα αρχεία αντί να εκτελέσει μια τυπική μετατροπή εικόνας.

### Επιλογή μορφών

Η **Μηχανή ** λίστα φίλτρων οι μορφές που εμφανίζονται στο ** Μορφή** πίνακα. Ένα όνομα μορφής περιγράφει τη λογική διάταξη του δίσκου· η επέκταση περιγράφει το δοχείο εξόδου. Ορισμένες μορφές μπορούν να αναπαρασταθούν από περισσότερες από μία επεκτάσεις, και ορισμένες δεξαμενές δεν μπορούν να διατηρήσουν κάθε χαρακτηριστικό μιας ακατέργαστης πηγής.

Επιλέξτε μόνο εξόδους που πραγματικά χρειάζεστε. Πολλαπλές μορφές είναι χρήσιμες κατά τη δημιουργία ενός αρχειακού master, ένα αντίγραφο συμβατό με εξομοιωτή, και ένα αντίγραφο για ένα άλλο εργαλείο ανάλυσης σε μια λειτουργία.

### Ονομασία εξόδου και ετικέτες

**Όνομα εξόδου ** σας επιτρέπει να ελέγχετε τα βασικά ονόματα που δημιουργούνται για επιλεγμένες μορφές. ** Προσθήκη ετικετών ** εφαρμογή του μοτίβου ονόματος αρχείου σε ** Επιλογές > Γενικά**. Ετικέτες μπορούν να κωδικοποιήσουν την οικογένεια, τη μορφή, την επέκταση, την ημερομηνία, ή την ώρα. Προεπισκόπηση του παραδείγματος στις Επιλογές πριν από τη μετατροπή μιας μεγάλης παρτίδας έτσι ώστε τα αρχεία να ονομάζονται με συνέπεια.

### Έλεγχος αποτελεσμάτων μετατροπής

Για κάθε ζητούμενη έξοδο:

1. Επιβεβαίωσε ότι δημιουργήθηκε ένα αρχείο.
2. Ελέγξτε την κονσόλα για κομμάτια ή τομείς που δεν μπορούν να αποκωδικοποιηθούν.
3. Άνοιγμα του αποτελέσματος σε **Disk Explorer** εάν περιέχει υποστηριζόμενο σύστημα αρχείων.
4. Συγκρίνετε την αναμενόμενη χωρητικότητα και το περιεχόμενο του δίσκου με την πηγή.

Μια μετατροπή μπορεί να ολοκληρωθεί κατά την αναφορά απώλειας πληροφοριών που είναι εγγενής στη μορφή προορισμού. Διατήρηση της αρχικής ακατέργαστης εικόνας ακόμη και όταν η μετατροπή της εικόνας φαίνεται σωστή.

## Οπτικοποίηση εικόνας δίσκου

Η **Οπτικοποίηση** Η καρτέλα εμφανίζει τη δομή και την κατανομή δεδομένων μιας εικόνας.

<p align="center"><img src="../images/main-visualization-en.png" alt="καρτέλα οπτικοποίησης" width="78%"></p>

1. Κλικ **Άνοιγμα εικόνας δίσκου**.
2. Διατήρηση **Αυτόματη ανίχνευση** ενεργοποιημένο, ή επιλέξτε το μηχάνημα και τη μορφή χειροκίνητα.
3. Χρήση **Εστίαση δεσμού** να διατηρούν και τις δύο πλευρές στο ίδιο επίπεδο εστίασης.
4. Χρήση **Επαναφορά** για να αποκατασταθεί η αρχική θέα.
5. Άνοιγμα **Επιθεωρητής** για λεπτομερείς πληροφορίες σχετικά με την επιλεγμένη περιοχή.

Ο θρύλος διακρίνει την κανονική ροή, τις σύντομες και μακριές μεταβάσεις, τις κεφαλές, τα αποκωδικοποιημένα δεδομένα και τις ανιχνεύσιμες ανωμαλίες. Μια ακατέργαστη εικόνα μπορεί να περιέχει δεδομένα που δεν μπορούν να αποκωδικοποιηθούν σε ένα γνωστό σύστημα αρχείων αλλά μπορούν ακόμα να επιθεωρηθούν εδώ.

### Ερμηνεύοντας την άποψη

Κάθε μεγάλος κυκλικός πίνακας αντιπροσωπεύει μια πλευρά δίσκου. Το κέντρο προσδιορίζει την πλευρά και την τρέχουσα κατάσταση δεδομένων του· ομόκεντρες θέσεις αντιστοιχούν σε κομμάτια. Τα χρώματα κατατάσσουν τις ανιχνευόμενες περιοχές σύμφωνα με το μύθο. Ο οπτικοποιητής προορίζεται να απαντήσει σε ερωτήσεις όπως:

- Η εικόνα περιέχει δεδομένα από τη μια πλευρά ή και από τις δύο;
- Είναι τα αναμενόμενα ίχνη παρόντα;
- Απομονώνονται ή επαναλαμβάνονται ανωμαλίες στο δίσκο;
- Αναγνώρισε η αυτόματη ανίχνευση μια αληθοφανής μηχανή και μορφή;

Ένα χρώμα ανωμαλίας είναι ένας λόγος για να επιθεωρήσετε την περιοχή, όχι απόδειξη ότι ο δίσκος δεν μπορεί να χρησιμοποιηθεί. Η προστασία αντιγράφων, η μη τυπική μορφοποίηση, η αδύναμη καταγραφή και ένας κατεστραμμένος τομέας μπορούν να παράγουν διαφορετικές δομές που απαιτούν ερμηνεία του πλαισίου.

### Συνιστώμενη ακολουθία επιθεώρησης

Ξεκινήστε με το συνδεδεμένο ζουμ ενεργοποιημένο για να συγκρίνετε και τις δύο πλευρές στην ίδια κλίμακα. Επιλέξτε μια ύποπτη περιοχή, ανοικτή **Επιθεωρητής**, και να το συγκρίνετε με γειτονικά κομμάτια. Εάν το αποτέλεσμα φαίνεται να είναι πρόβλημα ανίχνευσης, απενεργοποιήστε την αυτόματη ανίχνευση και επιλέξτε μια γνωστή μηχανή και μορφή. Επιστρέψτε στην αυτόματη ανίχνευση μετά τη δοκιμή έτσι ώστε μια αναγκαστική ρύθμιση να μην χρησιμοποιείται τυχαία για άλλη εικόνα.

## Εξερευνώντας το περιεχόμενο του δίσκου

Η **Disk Explorer** καρτέλα περιηγείται υποστηριζόμενες εικόνες δίσκων ως ιεραρχία αρχείων.

<p align="center"><img src="../images/main-disk-explorer-en.png" alt="Disk Explorer καρτέλα" width="78%"></p>

1. Ανοίξτε μια υπάρχουσα εικόνα ή διαβάστε ένα δίσκο.
2. Διατήρηση **Αυτόματη ανίχνευση** ενεργοποιημένο εκτός αν χρειαστεί να αναγκάσεις μια μηχανή ή μια μορφή.
3. Επανεξέταση των πληροφοριών όγκου: σύστημα, προστασία, σύστημα αρχείων, χωρητικότητα, ελεύθερος χώρος και αριθμός στοιχείων.
4. Περιήγηση καταλόγων στον αριστερό πίνακα.
5. Επιλέξτε ένα αντικείμενο για να δείτε τα στοιχεία του στο δεξί πίνακα.

Εάν η μορφή εικόνας ή το σύστημα αρχείων δεν υποστηρίζεται, χρησιμοποιήστε **Οπτικοποίηση** να επιθεωρήσει την ακατέργαστη δομή αντ 'αυτού.

### Κατανόηση των πάνελ

Η πάνω περίληψη περιγράφει την προσαρτημένη εικόνα και ανιχνεύει όγκο. Ο κάτω-αριστερός πίνακας περιέχει την ιεραρχία καταλόγου. Ο κεντρικός πίνακας παραθέτει στοιχεία στον επιλεγμένο κατάλογο με όνομα, ημερομηνία τροποποίησης, τύπο και μέγεθος. Ο δεξιός πίνακας εμφανίζει λεπτομέρειες για το επιλεγμένο αντικείμενο.

Disk Explorer δεν υπονοεί ότι κάθε ακατέργαστο κομμάτι αποκωδικοποιήθηκε τέλεια. Χρησιμοποιήστε την περίληψη έντασης και το αντικείμενο μετρούν ως ένα γρήγορο έλεγχο αληθοφάνειας, στη συνέχεια, ανοίξτε αντιπροσωπευτικά αρχεία ή να τα συγκρίνετε με ένα γνωστό κατάλογο λίστα όταν η ακρίβεια διατήρησης θέματα.

### Όταν δεν εμφανίζεται τίποτα

Πρώτα επιβεβαιώστε ότι η διαδρομή της εικόνας είναι σωστή. Στη συνέχεια, ελέγξτε την ανιχνευμένη μηχανή και τη μορφή. Μια έγκυρη εικόνα μπορεί να περιέχει ένα μη υποστηριζόμενο ή κατεστραμμένο σύστημα αρχείων, οπότε ο εξερευνητής μπορεί να παραμείνει κενός ακόμα και αν **Οπτικοποίηση** δείχνει καταγεγραμμένα δεδομένα. Μην αντικαταστήσετε ή απορρίψετε την εικόνα πηγής με βάση μόνο έναν άδειο εξερευνητή.

## Χρήση εργαλείων

Η **Εργαλεία** ομάδες καρτελών Greaseweazle εργασίες συντήρησης.

<p align="center"><img src="../images/main-tools-en.png" alt="Καρτέλα εργαλείων" width="78%"></p>

Επιλέξτε μια εντολή από τη λίστα στα αριστερά, ελέγξτε τις παραμέτρους της και στη συνέχεια κάντε κλικ **Εκτέλεση**. Καταστροφικές ή εντολές αλλαγής υλικού θα πρέπει να χρησιμοποιούνται μόνο μετά την επαλήθευση του επιλεγμένου ελεγκτή και κίνησης.

Οι περισσότεροι διάλογοι εργαλείων περιέχουν τρεις περιοχές: παραμέτρους στην κορυφή, μια κατάσταση και την περιοχή ακατέργαστης εξόδου στο κέντρο, και η παραγόμενη εντολή στο κάτω μέρος. Μια μη ελεγχόμενη παράμετρος κανονικά σημαίνει “μη τροποποίηση αυτής της τιμής”, ενώ μια ελεγχόμενη παράμετρος περιλαμβάνει αυτή την τιμή στην εντολή.

Οι επιμέρους διαγνωστικοί διάλογοι περιγράφονται στο [Hardware διαγνωστικά και συντήρηση](#hardware-diagnostics-and-maintenance).

Η **Εξομοίωση ** λίστες καρτελών αποθηκευμένες ρυθμίσεις. Επιλέξτε ένα και κάντε κλικ ** Άνοιγμα**Κάθε μηχανή που τρέχει εμφανίζεται στη δική του καρτέλα.

Μια αποθηκευμένη διαμόρφωση συνδυάζει το μοντέλο μηχανής, έκδοση εξομοιωτή, ROM, μνήμη, βίντεο, ήχου, αποθήκευσης, και χαρτογραφήσεις εισόδου. Η αποθήκευση μιας ρύθμισης δεν την εκκινεί· επιστροφή στην κύρια **Εξομοίωση ** καρτέλα και κλικ ** Άνοιγμα**.

### Χειριστήρια για μηχανές κίνησης

<p align="center"><img src="../images/main-emulation-running-en.png" alt="Τροχαίο μιμούμενο μηχάνημα" width="78%"></p>

Η γραμμή εργαλείων τρεξίματος-μηχανής παρέχει ισχύ, παύση, επαναφορά, αποθήκευση-κατάσταση, κατάσταση φόρτωσης, σύλληψη, και ελέγχου οθόνης. Δείχνει επίσης:

- τις ρυθμισμένες συντομεύσεις γρήγορης αποθήκευσης και γρήγορης φόρτωσης·
- ο ενεργός δέκτης, όπως Direct3D 11;
- τις συντομεύσεις πλήρους οθόνης και απελευθέρωσης ποντικιού·
- κατάσταση ήχου, ελεγκτή και ποντικιού·
- η τρέχουσα ανάλυση, ο ρυθμός ανανέωσης και ο ρυθμός καρέ.

Η ταινία δίσκου στο κάτω μέρος της οθόνης εξομοίωσης διαχειρίζεται τα μετακινούμενα μέσα για κάθε εξομοίωση κίνησης. Οι εργασίες πληκτρολογίου μπορούν να αλλάξουν σε **Επιλογές > Εξομοίωση > Συντομεύσεις**, ενώ μιμούνται πληκτρολόγιο, ποντίκι, και χαρτογραφήσεις ελεγκτή ρυθμίζονται στις αντίστοιχες Amiga καρτέλες.

### Αναφορά γραμμής εργαλείων

| Ομάδα ελέγχου | Αντικείμενο |

| Εμφάνιση | Αλλάζει την παρουσίαση της οθόνης ή μπαίνει σε πλήρη οθόνη |
| Υπενθύμιση γρήγορης κατάστασης | Εμφάνιση των ενεργών συντομεύσεων αποθήκευσης/φόρτωσης |

### Φεύγοντας από την πλήρη οθόνη ή απελευθερώνοντας το ποντίκι

Η γραμμή εργαλείων εμφανίζει τα τρέχοντα καθορισμένα πλήκτρα. Στην εικονογραφημένη διαμόρφωση, **Αλτ+ Επιστροφή ** Εναλλαγή πλήρους οθόνης και ** ΣΤ12** απελευθερώνει το ποντίκι. Αντιμετώπιση των εμφανιζόμενων τιμών ως έγκυρες επειδή οι συντομεύσεις μπορούν να επανατοποθετηθούν.

### Χρήση μέσων δισκέτας

Η ταινία κίνησης προσδιορίζει κάθε μονάδα προσομοίωσης, όπως `DF0:`. Χρησιμοποιήστε τα μέσα ελέγχου του για να εισάγετε, να αντικαταστήσετε ή να εκτινάξετε μια εικόνα. Η αντικατάσταση των μέσων αλλάζει μόνο τον εισαγόμενο δίσκο του μηχανήματος που εκτελείται.Δεν αλλάζει τον ορισμό αποθήκευσης-συσκευής στο αποθηκευμένο μηχάνημα εκτός εάν αυτή η ενέργεια είναι σαφώς αποθηκευμένη.

## Επιλογές εφαρμογής

Άνοιγμα **Επιλογές** από το κύριο παράθυρο για τη ρύθμιση της εφαρμογής.

### Γενικά

<p align="center"><img src="../images/options-general-en.png" alt="Γενικές επιλογές" width="72%"></p>

Η **Γενικά** Η καρτέλα περιέχει:

- τον προκαθορισμένο φάκελο εικόνας δίσκου·
- γλώσσα και θέμα διεπαφής·
- δημιουργία ετικέτας αρχείου για μετατροπές·
- προκαθορισμένα και πρόσφατα πρότυπα προσαρμοσμένων ετικετών·
- ένα ζωντανό παράδειγμα ονόματος αρχείου.

Οι μεταβλητές ετικέτας περιλαμβάνουν το πηγαίο όνομα, την οικογένεια, τη μορφή, την επέκταση, την ημερομηνία και την ώρα. Χρησιμοποιήστε το κουμπί επαναφοράς για την επαναφορά του προκαθορισμένου μοτίβου.

Οι ενημερώσεις προεπισκόπησης ονομάτων αρχείων πριν από τη δημιουργία αρχείων. Χρησιμοποιήστε το για να ανιχνεύσετε διπλούς διαχωριστές, λείπουν επεκτάσεις, ή διφορούμενα ονόματα. Πρόσφατα προσαρμοσμένα μοτίβα παρέχουν γρήγορη πρόσβαση σε προγενέστερα συστήματα ονοματοδοσίας χωρίς αντικατάσταση της τρέχουσας προεπιλογής.

### Καταγραφές

<p align="center"><img src="../images/options-logs-en.png" alt="Επιλογές καταγραφής" width="72%"></p>

Η καταγραφή μπορεί να ρυθμιστεί ανεξάρτητα για κάθε λειτουργία. Για κάθε κατηγορία, επιλέξτε αν πρέπει να αποθηκεύσετε αρχεία καταγραφής, να ορίσετε ένα μέγιστο μέγεθος αρχείου και να αποφασίσετε αν θα πρέπει να διατηρηθούν προηγούμενα αρχεία καταγραφής. Μέγεθος `0` σημαίνει απεριόριστη. **Άνοιγμα φακέλου** ανοίγει τον τρέχοντα κατάλογο καταγραφής.

Ενεργοποίηση **Διατήρηση προηγούμενων αρχείων καταγραφής** για τη διατήρηση και τη διαγνωστική εργασία όπου η ιστορία πολλών προσπαθειών έχει σημασία. Απενεργοποίηση όταν μόνο το πιο πρόσφατο αποτέλεσμα είναι χρήσιμο. Τα μέγιστα όρια μεγέθους ισχύουν για την αποθήκευση καταγραφής, όχι για τις εικόνες δίσκου που αιχμαλωτίζονται.

### Χειριστές και οδηγοί

<p align="center"><img src="../images/options-controllers-and-drives-en.png" alt="Χειριστές και οδηγοί" width="72%"></p>

Χρήση αυτής της καρτέλας σε:

- σάρωση για συνδεδεμένους ελεγκτές·
- να προσθέτει και να αφαιρεί ρυθμίσεις κίνησης·
- επιλογή μεγέθους κίνησης, πυκνότητας και ταχύτητας·
- αποθήκευση ρυθμίσεων υλικού·
- επιλογή ή αυτόματη εύρεση `gw.exe`;
- έλεγχος και λήψη Greaseweazle Host Tools ενημερώσεις·
- επαναφορά μιας προηγουμένως ρυθμισμένης εκτελέσιμης διαδρομής.

Οι αποθηκευμένες ρυθμίσεις υλικού παραμένουν διαθέσιμες όταν μια μονάδα αποσυνδέεται προσωρινά.

#### Προσθήκη δίσκου

1. Κλικ **Σάρωση** και περιμένετε να εμφανιστούν συνδεδεμένοι ελεγκτές.
2. Κλικ **Προσθήκη δίσκου** εάν η απαιτούμενη κίνηση δεν είναι ήδη καταχωρισμένη.
3. Επιλέξτε τον λογικό αριθμό κίνησης, το φυσικό μέγεθος, την πυκνότητα καταγραφής και την ταχύτητα περιστροφής.
4. Σώσε τη σειρά.
5. Επιβεβαιώστε ότι δείχνει **Διαθέσιμο ** και ** Configure**.

Χρησιμοποιήστε τον έλεγχο απορριμμάτων μόνο για να αφαιρέσετε τις αποθηκευμένες ρυθμίσεις. Εάν ο ίδιος ελεγκτής εμφανιστεί σε διαφορετικό COM Θύρα αργότερα, σαρώστε ξανά πριν υποθέσετε ότι η αποθηκευμένη θύρα εξακολουθεί να ισχύει.

#### Διαχείριση Greaseweazle Host Tools

**Αναζήτηση gw.exe ** ψάχνει γνωστές τοποθεσίες. ** Επιλογή ** επιλέγει ένα συγκεκριμένο εκτελέσιμο. ** Έλεγχος για ενημερώσεις ** ερωτήματα διαθέσιμες εκδόσεις χωρίς την αντικατάσταση του εγκατεστημένου. ** Λήψη της τελευταίας έκδοσης ** εγκαθιστά το επιλεγμένο τρέχον πακέτο, και ** Χρήση προηγούμενης διαδρομής ** αποκαθιστά την προγενέστερη διαμορφωμένη τοποθεσία. Μετά την αλλαγή του εκτελέσιμου, εκτελέστε ** Πληροφορίες ελεγκτή** για να επιβεβαιωθεί ότι η επιλεγμένη έκδοση μπορεί να επικοινωνήσει με τον ελεγκτή.

### Κινητήρες

<p align="center"><img src="../images/options-engines-en.png" alt="Επιλογή κινητήρα" width="72%"></p>

Επιλέξτε τον κινητήρα ανεξάρτητα για ανάγνωση, γραφή, μετατροπή, και Disk Explorer. Ο επιλεγμένος κινητήρας χρησιμοποιείται αυστηρά: αν δεν μπορεί να εκτελέσει την ζητούμενη λειτουργία, GW GUI αναφέρει τον περιορισμό αντί για σιωπηλή εναλλαγή κινητήρων.

Αυτή η ανεξαρτησία είναι σκόπιμη. Για παράδειγμα, η σωματική ανάγνωση μπορεί να χρησιμοποιήσει Greaseweazle Host Tools ενώ η μετατροπή εικόνας και η εξερεύνηση χρησιμοποιούν τον εσωτερικό κινητήρα. Καταγράψτε τις επιλογές μηχανών σε ένα προφίλ ή ένα σημείωμα έργου όταν έχει σημασία η αναπαραγωγιμότητα.

### Προφίλ

<p align="center"><img src="../images/options-profiles-en.png" alt="Προφίλ" width="72%"></p>

Τα προφίλ αποθηκεύουν επαναχρησιμοποιήσιμες ρυθμίσεις για διαβασμένες, γράψτε και μετατροπές. Επιλέξτε τη σχετική κατηγορία για τη διαχείριση των προφίλ της. Ένα επιλεγμένο προφίλ εμφανίζεται στη γραμμή κατάστασης κύριου παραθύρου και σε οθόνες λειτουργίας.

Χρήση προφίλ για επαναλαμβανόμενες ροές εργασίας και όχι ως ανεξήγητες συλλογές σημαιών εμπειρογνωμόνων. Δώστε σε κάθε προφίλ ένα όνομα ειδικού σκοπού, όπως μια συγκεκριμένη κίνηση, οικογένεια δίσκων, ή μέθοδος ανάκτησης. Επανεξέταση ενός προφίλ μετά την ενημέρωση του υποκείμενου κινητήρα, επειδή οι υποστηριζόμενες επιλογές μπορούν να αλλάξουν.

## Επιλογές εξομοίωσης

Η **Εξομοίωση** οι επιλογές περιέχουν γενικές ρυθμίσεις αποθήκευσης, καθολικές συντομεύσεις, αποθηκευμένες ρυθμίσεις και ειδικές για το μηχάνημα ρυθμίσεις.

### Γενικοί φάκελοι προσομοίωσης

<p align="center"><img src="../images/options-emulation-general-en.png" alt="Γενικές επιλογές προσομοίωσης" width="72%"></p>

Ορισμός του κοινόχρηστου φακέλου αποθήκευσης εξομοίωσης και των προκαθορισμένων φακέλων για τις λήψεις και τις αποθηκευμένες καταστάσεις. **Άνοιγμα φακέλου** ανοίγει την κοινή τοποθεσία στο File Explorer.

Κρατήστε τις λήψεις και τις αποθηκευμένες καταστάσεις σε ξεχωριστούς φακέλους. Μια σύλληψη είναι μια συνηθισμένη εικόνα; μια αποθηκευμένη κατάσταση περιέχει εξομοιωτή-ειδική κατάσταση μηχανής και μπορεί να εξαρτάται από την έκδοση εξομοιωτή και τη διαμόρφωση που την δημιούργησε. Δημιουργία αντιγράφων ασφαλείας στη διαμόρφωση και τα μέσα ενημέρωσης παράλληλα με σημαντικές αποθηκευμένες καταστάσεις.

### Γενικές συντομεύσεις

<p align="center"><img src="../images/options-emulation-shortcuts-en.png" alt="Συντομεύσεις εξομοίωσης" width="72%"></p>

Αναζητήστε μια ενέργεια ή μια βασική ανάθεση, εκχωρήστε ή αφαιρέστε συντομεύσεις, αποκαταστήστε τις προεπιλογές, και σαφείς συγκρούσεις. Η στήλη κατάστασης προσδιορίζει έγκυρες και αντικρουόμενες αναθέσεις.

Για να αλλάξετε μια συντόμευση, βρείτε την ενέργεια, κάντε κλικ **Ορισμός **, και πατήστε τον επιθυμητό συνδυασμό κλειδιών. Ελέγξτε την κατάσταση πριν το κλείσιμο των επιλογών. ** Καθαρισμός συγκρούσεων ** αφαιρεί αντικρουόμενες εκχωρήσεις· δεν αποκαθιστά την προκαθορισμένη χαρτογράφηση. Χρήση ** Επαναφορά προκαθορισμένων** όταν θέλετε να αντικαταστήσετε τις προσαρμοσμένες αναθέσεις με το πρότυπο σύνολο.

### Αποθηκευμένες ρυθμίσεις

<p align="center"><img src="../images/options-emulation-configurations-en.png" alt="Αποθηκευμένες ρυθμίσεις προσομοίωσης" width="72%"></p>

Αυτή η σελίδα περιλαμβάνει αποθηκευμένες μηχανές. Επιλέξτε μια ρύθμιση για την επεξεργασία του στο **Amiga** καρτέλα. Μπορείτε να ανανεώσετε τη λίστα ή να διαγράψετε τις επιλεγμένες ρυθμίσεις.

Η διαγραφή μιας ρύθμισης αφαιρεί τον αποθηκευμένο ορισμό μηχανής. Δεν πρέπει να χρησιμοποιείται ως τρόπος εκτίναξης μέσων ή κλεισίματος μηχανής λειτουργίας. Πριν τη διαγραφή, σημειώστε οποιαδήποτε ROM, εικόνα σκληρού δίσκου, και state αρχεία που σχετίζονται με τις ρυθμίσεις.

## Amiga διαμόρφωση

Η τρέχουσα διεπαφή παρέχει λεπτομερείς πληροφορίες Amiga σελίδες ρυθμίσεων. Η ίδια δομή ρυθμίσεων μπορεί να επεκταθεί και για άλλα συστήματα προσομοίωσης χωρίς αλλαγή της κύριας ροής εργασίας.

### Γενικά

<p align="center"><img src="../images/options-amiga-general-en.png" alt="Amiga γενικές ρυθμίσεις" width="72%"></p>

Επιλέξτε το Amiga μοντέλο, αποθηκεύστε τις ρυθμίσεις, εγκαταστήστε ή αντικαταστήστε την έκδοση εξομοιωτή, και καθορίστε προκαθορισμένους φακέλους για τους σκληρούς δίσκους και άλλα μέσα. **Αναζήτηση εκδόσεων** διερωτάται η επίσημη πηγή εξομοιωτή-έκδοση.

Ξεκινήστε με το μοντέλο γιατί περιορίζει τις επόμενες σελίδες. Αλλάζοντας το μπορεί να αλλάξει το διαθέσιμο CPU, μνήμη, ROM, chipset, και επιλογές αποθήκευσης. Αφού επιλέξετε μια έκδοση εξομοιωτή, αποθηκεύστε τις ρυθμίσεις πριν την έναρξη από το κύριο παράθυρο. Η εγκατάσταση μιας άλλης έκδοσης εξομοιωτή αντικαθιστά την έκδοση που χρησιμοποιείται από αυτές τις ρυθμίσεις· δεν δημιουργεί δεύτερο αντίγραφο του μηχανήματος.

### CPU

<p align="center"><img src="../images/options-amiga-cpu-en.png" alt="Amiga CPU settings" width="72%"></p>

Η CPU σελίδα δείχνει τον επεξεργαστή που επιλέχθηκε από το μοντέλο μηχανής και παρέχει συμβατή ακρίβεια, FPU, και επιλογές ταχύτητας. Οι επιλογές που δεν ισχύουν για το επιλεγμένο μοντέλο παραμένουν απενεργοποιημένες.

- **CPU μοντέλο** προσδιορίζει τον εξομοιούμενο επεξεργαστή.
- **Ακρίβεια** ελέγχει το μοντέλο συγχρονισμού. Οι κυκλικοί-ακριβείς τρόποι ευνοούν τη συμβατότητα υλικού αλλά απαιτούν περισσότερη επεξεργασία υπολογιστή.
- **FPU** επιτρέπει μια συμβατή μονάδα κινητής υποδιαστολής όταν υποστηρίζεται.
- **CPU ταχύτητα** επιλέγει τον αρχικό χρόνο ή έναν επιταχυνόμενο τρόπο.

Για μια βασική ρύθμιση, διατηρήστε το μοντέλο που προέρχεται από το μοντέλο CPU και αρχική ταχύτητα. Αλλάξτε την επιτάχυνση μόνο μετά τις μπότες μηχανή σωστά στις τυποποιημένες ρυθμίσεις του.

### RAM

<p align="center"><img src="../images/options-amiga-ram-en.png" alt="Amiga RAM settings" width="72%"></p>

Configure τσιπ RAM, Αργά RAM, Γρήγορα RAM, και υποστήριξε τη μνήμη επέκτασης. Τα μηνύματα συμβατότητας εξηγούν τους περιορισμούς για την επιλεγμένη μηχανή, και η συνολική ρυθμισμένη μνήμη εμφανίζεται στο κάτω μέρος.

**Τσιπ RAM ** είναι προσβάσιμο στα προσαρμοσμένα τσιπ και απαιτείται από την πλατφόρμα. ** Αργά RAM ** αντιπροσωπεύει συμβατή μνήμη επέκτασης που χρησιμοποιείται από κοινές διαμορφώσεις. ** Γρήγορα. RAM ** είναι μνήμη επέκτασης προσανατολισμένη στον επεξεργαστή. ** Ζορρό ΙΙΙ RAM** εφαρμόζεται μόνο σε μοντέλα που υποστηρίζουν την αρχιτεκτονική επέκτασης. Τα μηνύματα συμβατότητας και οι απενεργοποιημένοι έλεγχοι εμποδίζουν συνδυασμούς που το επιλεγμένο μοντέλο δεν μπορεί να αναπαραστήσει.

### ROM

<p align="center"><img src="../images/options-amiga-rom-en.png" alt="Amiga ROM settings" width="72%"></p>

Επιλέξτε το σύστημα Kickstart ROM, προαιρετική παράταση ROM, και ROM Κλειδί. Το ανιχνευμένο...ROM λίστα εμφανίζει ονόματα, αναθεωρήσεις και συμβατότητα με το επιλεγμένο μοντέλο. Επιλέξτε ένα ανιχνευμένο ROM και κλικ **Χρήση**, ή περιηγηθείτε σε ένα αρχείο χειροκίνητα.

ROM αρχεία δεν παρέχονται από GW GUI. Χρησιμοποιήστε τα ROM που επιτρέπεται νόμιμα να χρησιμοποιήσετε.

Η λίστα ανίχνευσης είναι προτιμότερη από την εικασία από ένα όνομα αρχείου: αναφέρει το ROM ταυτότητα και αναθεώρηση και αξιολογεί τη συμβατότητα με το επιλεγμένο μοντέλο. **Συμβατό ** είναι η κανονική επιλογή· ** Μερικώς συμβατό ** δείχνει ότι η ROM μπορεί να εκκινήσει αλλά δεν ταιριάζει ακριβώς με το μηχάνημα. ** Ανανέωση ** rescans το ρυθμισμένο ROM τοποθεσίες. ** Χρήση** ορίζει το επιλεγμένο ανιχνευμένο ROM στη διαμόρφωση.

### Βίντεο

<p align="center"><img src="../images/options-amiga-video-en.png" alt="Amiga settings βίντεο" width="72%"></p>

Ρυθμίστε το πρότυπο βίντεο, αναλογία διαστάσεων, ανάλυση, λειτουργία γραμμής, συνοριακή καλλιέργεια, απόδοση, βάθος χρώματος, skipping καρέ, γάμμα, και flicker στερέωση. Επιπλέον ρυθμίσεις chipset είναι διαθέσιμες περαιτέρω κάτω από τη σελίδα, όταν υποστηρίζεται από το επιλεγμένο μοντέλο.

| Setting | Πρακτικό αποτέλεσμα |
|---|---|
| Πρότυπο βίντεο | Επιλογή PAL ή NTSC χρονοδιάγραμμα και αναμενόμενη συμπεριφορά ανανέωσης |
| Αναλογία διαστάσεων | Ελέγχει τον τρόπο με τον οποίο κλιμακώνεται η εικόνα |
| Ανάλυση | Επιλογή αυτόματης ή ρητής λεπτομέρειας εξόδου |
| Λειτουργία γραμμής | Ελέγχεται η επεξεργασία της παρεμβαλλόμενης εξόδου ή της διπλής εξόδου με γραμμή |
| Σύνορα καλλιεργειών | Αφαίρεση αχρησιμοποίητης σάρωσης μόνο όταν είναι ενεργοποιημένη |
| Αποτύπωση | Επιλογή του συστήματος υποστήριξης γραφικών |
| Βάθος χρώματος | Επιλογή ακρίβειας χρώματος εξόδου |
| Παράλειψη πλαισίου | Μειώνει τα επεξεργασμένα πλαίσια όταν ενεργοποιούνται |
| Γάμμα | Ρυθμίζει την απόκριση φωτεινότητας |
| Επιδιορθωτής Flicker | Διεργασίες που διαφορετικά θα έτρεμαν ορατά |

Αλλάξτε μια ρύθμιση οθόνης κάθε φορά. Εάν το παράθυρο εξομοίωσης γίνει κενό ή ασταθές, επιστρέψτε στην αυτόματη ανάλυση, απενεργοποιημένο skip καρέ, ουδέτερο γάμμα, και ο προηγουμένως εργαζόμενος αποθέτης.

### Ήχος

<p align="center"><img src="../images/options-amiga-audio-en.png" alt="Amiga settings ήχου" width="72%"></p>

Ενεργοποίηση ή απενεργοποίηση ήχου, επιλέξτε τη συσκευή εξόδου και λανθάνουσας λειτουργίας, και στη συνέχεια ρυθμίστε παρεμβολή, Amiga φιλτράρισμα, τύπος φίλτρου, στερεοφωνικός διαχωρισμός, δισκέτα-drive ήχο, και CD-audio ένταση.

Χαμηλότερη λανθάνουσα καθυστέρηση μειώνει, αλλά μπορεί να προκαλέσει πτώση-outs σε ένα πολυάσχολο υπολογιστή. Αυξήστε το αν ο ήχος σπάσει. Παρεμβολή και Amiga audio filter change sound reproduction και όχι εικονιζόμενη λογική προγράμματος. Ο ήχος κίνησης ελέγχει τον προσομοιωμένο μηχανικό ήχο χωριστά από τον κανονικό Amiga Ήχος.

### Αποθήκευση

<p align="center"><img src="../images/options-amiga-storage-en.png" alt="Amiga settings αποθήκευσης" width="72%"></p>

Στη σελίδα αποθήκευσης παρατίθενται τα αναγνωριστικά συσκευών, οι τύποι, τα μοντέλα, τα σχετικά μέσα και οι διαθέσιμες ενέργειες. Προσθήκη, ρύθμιση ή αφαίρεση συσκευών εδώ. Οι δισκέτες και τα CD μπορούν να εισαχθούν ή να αντικατασταθούν απευθείας από μια μηχανή που τρέχει.

Η **Αναγνωριστικό συσκευής ** είναι ο τρόπος με τον οποίο το μιμούμενο σύστημα αντιμετωπίζει τη συσκευή. ** Τύπος ** διακρίνει δισκέτα, σκληρό δίσκο, οπτικές και άλλες υποστηριζόμενες συσκευές. ** Μοντέλο ** περιγράφει το εξομοιωμένο υλικό, ενώ ** Συνδεδεμένα μέσα** προσδιορίζει την τρέχουσα καθορισμένη εικόνα. Ρυθμίστε τη συσκευή πριν συνδέσετε πολύτιμα εγγράψιμα μέσα και κρατήστε αντίγραφα ασφαλείας από εικόνες σκληρού δίσκου.

### Πληκτρολόγιο

<p align="center"><img src="../images/options-amiga-keyboard-en.png" alt="Amiga settings πληκτρολογίου" width="72%"></p>

Αναζήτηση Amiga κλειδιά και αναθέσεις host, εκχώρηση νέων κλειδιών, αφαίρεση χαρτογραφήσεων, αποκατάσταση προεπιλεγμένων, ή σαφείς συγκρούσεις. Η στήλη κατάστασης αναφέρει αν κάθε ανάθεση είναι έγκυρη.

Η αριστερή στήλη ονομάζει την προσομοίωση Amiga κλειδί· **Ένωση** δείχνει το συνδυασμό κλειδιών υποδοχής. Μια έγκυρη χαρτογράφηση μπορεί ακόμα να είναι άβολη αν τα Windows ή η εφαρμογή διατηρεί την ίδια συντόμευση, οπότε ελέγξτε κρίσιμους συνδυασμούς στο εσωτερικό του μηχανήματος που εκτελείται. Αποφύγετε να ορίσετε τη συντόμευση του ποντικιού ή της πλήρους οθόνης σε ένα κλειδί που χρειάζεται συχνά το λογισμικό προσομοίωσης.

### Ποντίκι

<p align="center"><img src="../images/options-amiga-mouse-en.png" alt="Amiga settings ποντικιού" width="72%"></p>

Ορισμός φυσικής ταχύτητας του ποντικιού, επιλέξτε ποιο αναλογικό ραβδί ελέγχει το ποντίκι, ρυθμίστε την αναλογική νεκρή ζώνη και την ταχύτητα, και ρυθμίστε τις αντιστοιχίες δράσης του ποντικιού. Επαναφορά προεπιλογών ή σαφείς συγκρούσεις χαρτογράφησης όταν είναι απαραίτητο.

Αυξήστε τη νεκρή ζώνη αν ένας ελεγκτής προκαλεί μετατόπιση δείκτη. Ρυθμίστε την ταχύτητα του αριστερού και του δεξιού χεριού ανεξάρτητα όταν ενεργοποιηθούν και τα δύο ραβδιά. Ο χαμηλότερος πίνακας χαρτογράφησης συνδέει τις εισροές με τα κουμπιά ή τις ενέργειες του ποντικιού· επιθεωρήστε την κατάστασή του σύγκρουσης μετά την αλλαγή χαρτογραφήσεων ελεγκτή αλλού.

### Ελεγκτές

<p align="center"><img src="../images/options-amiga-controllers-en.png" alt="Amiga settings ελεγκτή" width="72%"></p>

Ανίχνευση συνδεδεμένων ελεγκτών, ανάθεση συσκευών και τύπων ελεγκτών σε Amiga θύρες, και να ρυθμίσετε χαρτογραφήσεις ελεγκτή και turbo-fire ρυθμίσεις. Οι διαθέσιμες επιλογές εξαρτώνται από το ανιχνευμένο υλικό και το επιλεγμένο μηχάνημα.

Η θύρα 1 και η θύρα 2 διαμορφώνονται ανεξάρτητα. **Αυτόματο** τύπος ελεγκτή είναι ένα λογικό σημείο εκκίνησης, αλλά το λογισμικό που περιμένει ένα συγκεκριμένο χειριστήριο ή το ποντίκι μπορεί να απαιτήσει ένα συγκεκριμένο τύπο. Εκτέλεση ανίχνευσης πριν από την ανάθεση ενός πρόσφατα συνδεδεμένου ελεγκτή. Turbo φωτιά ενεργοποιεί επανειλημμένα ένα χάρτη εισόδου και θα πρέπει να παραμείνει απενεργοποιημένο, εκτός εάν το παιχνίδι ή η εφαρμογή επωφελείται από αυτό.

## Διαγνωστικά υλικού και συντήρηση

Αυτοί οι διάλογοι ανοίγουν από το **Εργαλεία ** καρτέλα. Κάθε διάλογος προεπισκοπεί το δημιουργημένο Greaseweazle Διοίκηση. Επανεξέτασέ το πριν κάνεις κλικ ** Εκτέλεση**.

### Πληροφορίες ελεγκτή

<p align="center"><img src="../images/tool-controller-information-en.png" alt="Πληροφορίες ελεγκτή" width="62%"></p>

Μια μη αναμενόμενη τιμή μπορεί να υποδεικνύει λάθος ρυθμισμένη ταχύτητα, μηχανικό ζήτημα ή πρόβλημα ρύθμισης μέτρησης.

Χρησιμοποιήστε ακραίες θέσεις μόνο όταν η διαδικασία υλικού τις απαιτεί ρητά.

Κανονική αναζήτηση είναι χρήσιμη για την επιβεβαίωση της κίνησης της κεφαλής ή τοποθέτηση πριν από ένα διαγνωστικό. Ακούστε για μη φυσιολογικές επαναλαμβανόμενες επιπτώσεις και να σταματήσει αν η ζητούμενη φιάλη είναι ακατάλληλη για την κίνηση. Αυτό το εργαλείο δεν διαβάζει ούτε επικυρώνει δεδομένα στον κύλινδρο προορισμού.

### Διαγνωστική ευθυγράμμιση κίνησης

<p align="center"><img src="../images/tool-drive-alignment-en.png" alt="Διαγνωστική ευθυγράμμιση κίνησης" width="62%"></p>

Εκτελείται επαναλαμβανόμενη ανάγνωση για ανάλυση ευθυγράμμισης κίνησης. Υποστηρίζει την επιλογή κομματιών, την επανάσταση και τους αριθμούς ανάγνωσης, την αποκωδικοποίηση μορφή, την ακατέργαστη ροή, τον δείκτη, την ταχύτητα, PLL, pensity-pin, σκληρό τομέα, TG43, και επιλογές ανάστροφων δεδομένων. Η εργασία ευθυγράμμισης απαιτεί κατάλληλη γνώση των μέσων αναφοράς και του υλικού.

Ξεκινήστε με ένα γνωστό δίσκο αναφοράς και το μικρότερο σύνολο παρακάμψεων. **Εναλλασσόμενα κομμάτια ** καθορίζει τις τροχιές και τις κεφαλές που λαμβάνονται υπόψη· ** Επαναστάσεις ανά διαδρομή ** ελέγχει κάθε διάρκεια του δείγματος· ** Αριθμός αναγνώσεων** καθορίζει την επανάληψη. Ενεργοποίηση ενός προσαρμοσμένου ορισμού δίσκων ή μορφή αποκωδικοποίησης μόνο όταν ταιριάζει με τα μέσα αναφοράς. Επιλογές όπως ψεύτικος δείκτης, σκληροί τομείς, PLL παρακάμψεις, ακίδες πυκνότητας και TG43 είναι ειδικά για το υλικό ή τη μορφή και μπορεί να ακυρώσει μια σύγκριση όταν χρησιμοποιείται λανθασμένα.

Με **Αλλαγή καρφίτσας** Απενεργοποίηση, η εντολή αμφισβητεί την καρφίτσα. Αυτή είναι η ασφαλέστερη προεπιλογή. Η αλλαγή ενός επιπέδου επηρεάζει άμεσα τον ελεγκτή I/O και πρέπει να γίνεται μόνο με το σωστό Greaseweazle τεκμηρίωση υλικού και καλωδίωση συνημμένων οδηγών.

## Ιστορικό καταγραφής και λειτουργίας

Ανοίξτε το ιστορικό λειτουργίας για να επιθεωρήσετε αποθηκευμένα αρχεία καταγραφής από τη λειτουργία.

<p align="center"><img src="../images/operation-history-en.png" alt="Ιστορικό λειτουργίας" width="68%"></p>

Επιλέξτε μια καταγραφή στα αριστερά για την εμφάνιση των περιεχομένων της. **Εξαγωγή** αποθηκεύει ένα αντίγραφο για διαγνωστικά ή υποστήριξη. Οι διαδρομές και οι γραμμές εντολών μπορεί να περιέχουν ονόματα προσωπικών φακέλων, έτσι ώστε να αναθεωρήσετε τα εξαγόμενα αρχεία καταγραφής πριν τα μοιραστείτε.

Η ζωντανή κονσόλα στο κύριο παράθυρο εμφανίζει την τρέχουσα εντολή και την πρόσφατη έξοδο. Το κουμπί αντιγραφής αντιγράφει το εμφανιζόμενο κείμενο.

### Ανάγνωση καταγραφής

Ένα χρήσιμο διαγνωστικό αρχείο καταγραφής περιέχει την παραγόμενη εντολή, χρονοσφραγίδες, έξοδο κινητήρα, και την τελική κατάσταση. Εργαστείτε από κάτω προς τα πάνω: αναγνωρίστε το τελικό σφάλμα, στη συνέχεια εντοπίστε την πρώτη προειδοποίηση ή απέτυχε κομμάτι που προηγήθηκε. Μια μεταγενέστερη γενική αποτυχία είναι συχνά μόνο η συνέπεια ενός προγενέστερου, πιο συγκεκριμένου μηνύματος.

Κατά τη σύγκριση δύο προσπαθειών, ελέγξτε ότι ο ελεγκτής, η κίνηση, η μηχανή, το προφίλ, η διαδρομή πηγής, η μορφή εξόδου, και τα επιχειρήματα εμπειρογνωμόνων ήταν πανομοιότυπα. Διαφορετικά, ένα διαφορετικό αποτέλεσμα μπορεί να αντανακλά αλλαγές ρυθμίσεων και όχι αστάθεια δίσκων.

## Δεδομένα εφαρμογής και φορητή χρήση

GW GUI διατηρεί τα δεδομένα του χρήστη χωριστά από τα δυαδικά της εφαρμογής. Ανάλογα με το επιλεγμένο πακέτο και τη λειτουργία, οι ρυθμίσεις, τα αρχεία καταγραφής, τα μεταφορτωμένα εργαλεία, τα εξαρτήματα εξομοιωτών, οι λήψεις, οι καταστάσεις και οι διαμορφώσεις μηχανών αποθηκεύονται είτε στην εφαρμογή `Data` κατάλογος ή στις ρυθμισμένες τοποθεσίες δεδομένων χρήστη.

Πριν αντικαταστήσετε ή μετακινήσετε μια φορητή εγκατάσταση, κρατήστε το πλήρες φάκελο εφαρμογής μαζί και back up το `Data` φάκελος. Μην μετακινείτε μεμονωμένα αρχεία από `lib`, διότι η εφαρμογή επιλύει τις δικές της βιβλιοθήκες και τις βιβλιοθήκες τρίτων μερών από αυτή τη δομή.

### Προτεινόμενο περιεχόμενο αντιγράφου ασφαλείας

Πίσω τα ακόλουθα όταν είναι σημαντικά για τη ροή εργασίας σας:

- ρυθμίσεις εφαρμογής και προφίλ·
- ορισμούς ελεγκτή και κίνησης·
- διαμορφώσεις εξομοίωσης·
- ROM μονοπάτια και νομικά κατοχυρωμένα ROM αντίγραφα ασφαλείας·
- εικόνες σκληρού δίσκου και αφαιρούμενων μέσων·
- συλλαμβάνει και σώζει καταστάσεις·
- αρχεία καταγραφής λειτουργίας που χρησιμοποιούνται ως αρχεία συντήρησης.

Οι εικόνες δίσκου μπορεί να είναι πολύ μεγαλύτερες από τις ρυθμίσεις. Αποθήκευση αρχειοθέτηση masters ανάγνωση μόνο όταν είναι δυνατόν, και εργασία σε αντίγραφα.

## Συνιστώμενες ροές εργασίας

### Αρχειοθέτηση ενός άγνωστου δίσκου

1. Επιθεωρήστε και καθαρίστε την κίνηση χρησιμοποιώντας κατάλληλη διαδικασία συντήρησης.
2. Γράψτε-προστατέψτε το δίσκο αν είναι δυνατόν.
3. Επιλογή **Ανάγνωση > Πρώτη εικόνα (SCP)**.
4. Χρησιμοποιήστε ένα περιγραφικό όνομα αρχείου και διαβάστε το κανονικό εύρος κομματιών με πολλαπλές στροφές.
5. Επανεξέταση της κονσόλας και αποθήκευση καταγραφής.
6. Έλεγχος και των δύο πλευρών **Οπτικοποίηση**.
7. Μετατροπή ενός αντιγράφου σε πιθανές μορφές τομέα.
8. Δοκιμάστε τα αντίγραφα που έχουν μετατραπεί σε **Disk Explorer** ή κατάλληλο λογισμικό.
9. Διατηρήστε μαζί τον ωμό αφέντη, τον κορμό και τις σημειώσεις.

### Αναδημιουργία ενός δίσκου από μια εικόνα

1. Ελέγξτε την εικόνα και επιβεβαιώστε την αναμενόμενη οικογένεια και μορφή της.
2. Εισάγετε ένα αναλώσιμο ή σκόπιμα εγγράψιμο δίσκο του σωστού μεγέθους και πυκνότητας.
3. Άνοιγμα **Εγγραφή** και επιλέξτε την εικόνα.
4. Επιβεβαίωση της ρυθμισμένης κίνησης και ανιχνευμένη μορφή.
5. Γράψε το δίσκο.
6. Διαβάστε το πίσω σε μια ξεχωριστή εικόνα επαλήθευσης.
7. Συγκρίνετε αποκωδικοποιημένα περιεχόμενα και ελέγξτε ύποπτα κομμάτια οπτικά.

### Δημιουργία ενός μιμούμενου Amiga

1. Άνοιγμα **Επιλογές > Εξομοίωση > Configuration** και να δημιουργήσετε ή να επιλέξετε μια μηχανή.
2. Μέσα **Amiga > Γενικά**, επιλέξτε το μοντέλο και την έκδοση εξομοιωτή.
3. Ανάθεση συμβατού, νομίμως αποκτηθέντος ROM.
4. Διατήρηση προεπιλεγμένων μοντέλων για CPU και RAM Στην πρώτη μπότα.
5. Configure βίντεο και ήχου με συντηρητικές αυτόματες ρυθμίσεις.
6. Προσθήκη συσκευών αποθήκευσης και συσχετιζόμενων αντιγράφων εικόνων μέσων.
7. Επανεξέταση πληκτρολόγιο, ποντίκι, και εργασίες ελεγκτή.
8. Αποθήκευση των ρυθμίσεων.
9. Επιστροφή σε **Εξομοίωση **, επιλέξτε το, και κάντε κλικ ** Άνοιγμα**.
10. Μόνο μετά από επιτυχή εκκίνηση εκκίνησης, αλλαγή επιτάχυνσης ή προχωρημένες ρυθμίσεις μία κάθε φορά.

## Κατάλογος ελέγχου ασφαλείας

Πριν **Ανάγνωση**:

- ο δίσκος πηγής βρίσκεται στη σωστή κίνηση·
- η πηγή προστατεύεται από εγγραφή, όπου είναι δυνατόν·
- η διαδρομή εξόδου δεν θα αντικαταστήσει υφιστάμενο κύριο·
- το προφίλ και το εύρος κομματιών ταιριάζουν με το δίσκο.

Πριν **Εγγραφή ** ή ** Σβήσιμο**:

- ο δίσκος προορισμού μπορεί να καταστραφεί·
- η εικόνα και η κίνηση είναι σωστές·
- το μέγεθος και η πυκνότητα του δίσκου είναι συμβατά·
- Κανένας αρχειάρχης δεν χρησιμοποιείται ως προορισμός.

Πριν από ένα εργαλείο αλλαγής υλικού:

- δεν εκτελείται άλλη λειτουργία·
- επιλέγεται ο σωστός ελεγκτής·
- έχουν καταγραφεί τρέχουσες τιμές·
- ο ελεγκτής έχει σταθερή ισχύ και USB συνδεσιμότητα·
- η ενέργεια υποστηρίζεται από την τεκμηρίωση υλικού.

## Αντιμετώπιση προβλημάτων

### Ο ελεγκτής δεν είναι καταχωρημένος

1. Επανασυνδέστε το χειριστήριο απευθείας στον υπολογιστή.
2. Άνοιγμα **Επιλογές > Χειριστές και οδηγοί**.
3. Κλικ **Σάρωση**.
4. Επαλήθευση της κατάστασης του ελεγκτή και της ρύθμισης κίνησης.
5. Εκτέλεση **Πληροφορίες ελεγκτή** αν η ανίχνευση πετύχει αλλά οι εντολές αποτύχουν.

Αν εξακολουθεί να μην εμφανίζεται, δοκιμάστε μια άλλη ευθεία USB Αριστερά και καλωδιακή, μετά επανασάρωσε. Ελέγξτε το Windows Device Manager για μια πρόσφατα ανιχνεύσιμη σειριακή συσκευή. Ένας ελεγκτής ορατός στα Windows αλλά απουσία από GW GUI συνήθως δείχνει μια πολυσύχναστη θύρα, μπαγιάτικη διαμόρφωση, ή το πρόβλημα Host Tools; ένας ελεγκτής που απουσιάζει από τα Windows δείχνει σε USB, δύναμη, οδηγός, ή υλικό.

### `gw.exe` δεν βρέθηκε

Άνοιγμα **Επιλογές > Χειριστές και οδηγοί **, στη συνέχεια χρήση ** Αναζήτηση gw.exe **, ** Επιλογή **, ή ** Λήψη της τελευταίας έκδοσης**. Επιβεβαιώστε ότι η ανιχνευθείσα διαδρομή δείχνει την προβλεπόμενη Greaseweazle εγκατάσταση.

Αφού το επιλέξετε, τρέξτε. **Πληροφορίες ελεγκτή**. Αν αυτό αποτύχει πριν από την επαφή με το υλικό, επιθεωρήστε το αρχείο καταγραφής για μια άκυρη εκτελέσιμη διαδρομή, λείπουν αρχεία, ή μια έκδοση που δεν μπορεί να ξεκινήσει.

### Μια λειτουργία χρησιμοποιεί λάθος κινητήρα

Άνοιγμα **Επιλογές > Κινητήρες** και ελέγξτε τον κινητήρα που έχει οριστεί για την ακριβή λειτουργία. GW GUI δεν υποχωρεί σιωπηρά στον άλλο κινητήρα.

Οι ρυθμίσεις του κινητήρα είναι ξεχωριστές: η αλλαγή του κινητήρα μετατροπής δεν αλλάζει ανάγνωση, γραφή, ή Disk Explorer. Επαναλειτουργία της λειτουργίας αποτυχίας μετά την αποθήκευση της επιλογής και επιβεβαίωση της παραγόμενης εντολής στην κονσόλα.

### Μια εικόνα δεν αναγνωρίζεται

Απενεργοποίηση αυτόματης ανίχνευσης μόνο αν γνωρίζετε τη σωστή μηχανή και μορφή. Διαφορετικά, δοκιμάστε το **Οπτικοποίηση** καρτέλα για την επιθεώρηση της εικόνας σε χαμηλότερο επίπεδο.

Ελέγξτε αν η πηγή είναι μια σύλληψη ακατέργαστης ροής, μια εικόνα τομέα, ένα συμπιεσμένο δοχείο, ή ένα μη συνδεδεμένο αρχείο με παραπλανητική επέκταση. Η μετατροπή πρέπει να ερμηνεύει σωστά τη δομή της πηγής.

### Η εξομοίωση δεν ξεκινά

Επαλήθευση αποθηκευμένων ρυθμίσεων, εγκατεστημένη έκδοση εξομοιωτή, επιλεγμένη ROM, μονοπάτια αποθήκευσης και συμβατότητα μοντέλου. Επανεξέτασε το αρχείο καταγραφής της εφαρμογής για τις πλήρεις λεπτομέρειες σφάλματος.

Προσωρινή επιστροφή CPU, RAM, βίντεο και αποθήκευση σε μια απλή βάση συμβατή με μοντέλο. Αν ξεκινήσει η αρχική γραμμή, επαναφέρετε μία προσαρμοσμένη ρύθμιση κάθε φορά. Μια αποθηκευμένη κατάσταση που δημιουργήθηκε με μια άλλη έκδοση εξομοιωτή ή ορισμό μηχανής μπορεί επίσης να αποτύχει ακόμη και όταν μια καθαρή εκκίνηση λειτουργεί.

### Μια συντόμευση ή εισαγωγή δεν λειτουργεί

Ελέγξτε τόσο το παγκόσμιο **Εξομοίωση > Συντομεύσεις** σελίδα και το πληκτρολόγιο, το ποντίκι ή τη σελίδα του ελεγκτή. Επίλυση οποιασδήποτε αποστολής χαρακτηρίζεται ως αντικρουόμενη.

Αν το ποντίκι συλληφθεί, χρησιμοποιήστε τη συντόμευση απελευθέρωσης που εμφανίζεται στη γραμμή εργαλείων μηχανής εκτέλεσης. Εάν ένας ελεγκτής συνδέθηκε μετά το άνοιγμα του Options, εκτελέστε και πάλι ανίχνευση ελεγκτή πριν από την εκχώρηση του.

### Μια εντολή αποτυγχάνει απροσδόκητα

1. Διαβάστε την έξοδο ζωντανής κονσόλας.
2. Άνοιγμα **Ιστορικό λειτουργίας** για το πλήρες αποθηκευμένο αρχείο καταγραφής.
3. Επιβεβαιώστε την επιλεγμένη διαδρομή ελέγχου, κίνησης, προφίλ, μηχανής και αρχείων.
4. Εξαγωγή του σχετικού ημερολογίου εάν πρέπει να μοιραστεί για διάγνωση.

### Ηχητικές ρωγμές ή παύσεις

Αύξηση λανθάνουσας μίμησης ήχου, κλείσιμο CPU-εντατικές εφαρμογές, και επιστροφή βίντεο πλαίσιο παρακάμπτοντας και επιτάχυνση στις προηγούμενες τιμές τους. Επαλήθευση της επιλογής της συσκευής ήχου των Windows. Αλλάξτε μια ρύθμιση κάθε φορά, έτσι ώστε η αποτελεσματική διόρθωση είναι αναγνωρίσιμη.

### Η απεικόνιση εξομοίωσης είναι κενή ή αργή

Ανάλυση επιστροφής και λειτουργία γραμμής **Αυτόματο**, απενεργοποιήστε το skipping καρέ και το flicker διορθώνοντας προσωρινά, και δοκιμάστε τον προηγουμένως λειτουργικό δέκτη. Επιβεβαίωση της ρύθμισης ROM και τα εισαγόμενα μέσα εκκίνησης είναι έγκυρα. Η FPS δείκτης βοηθά στη διάκριση ενός προβλήματος απόδοσης απόδοσης από ένα μηχάνημα που απλά δεν έχει εκκινήσει.

### Μια ανάγνωση περιέχει ασταθή κομμάτια

Επαναλάβετε την ανάγνωση σε ένα νέο όνομα αρχείου, να αυξήσει τις επαναστάσεις όπου χρειάζεται, και να συγκρίνουν τα επηρεαζόμενα κομμάτια. Καθαρίστε τις κεφαλές κίνησης χρησιμοποιώντας μια σωστή διαδικασία και επιθεωρήστε το δίσκο για φυσική βλάβη. Μην διαβάζετε επανειλημμένα ορατά μέσα χύτευσης ή βλάβης, επειδή περαιτέρω περάσματα μπορεί να το επιδεινώσουν.

## Γλωσσάριο

| Όρος | Σημασία GW GUI |
|---|---|
| Ελεγκτής | Η Greaseweazle διασύνδεση υλικού συνδεδεμένο πάνω USB |
| Οδήγα | Η φυσική δισκέτα που συνδέεται με το χειριστήριο |
| Κινητήρας | Η υλοποίηση που επιλέχθηκε για την εκτέλεση μιας πράξης |
| Φλούξ | Πληροφορίες συγχρονισμού που αναπαριστούν μαγνητικές μεταβάσεις που διαβάζονται από ένα δίσκο |
| Ακατέργαστη εικόνα | Μια σύλληψη διατήρηση πληροφοριών χαμηλού επιπέδου δίσκου, όπως SCP |
| Εικόνα τομέα | Μια αποκωδικοποιημένη αναπαράσταση οργανωμένη σε λογικούς τομείς |
| Επανάσταση | Ένα πλήρες δείγμα περιστροφής κατά την ανάγνωση ενός κομματιού |
| Κύλινδρος | Ακτινωτή θέση κεφαλής· ένας κύλινδρος μπορεί να περιέχει τροχιά σε κάθε πλευρά |
| Υπεύθυνος | Η πλευρά του δίσκου που επιλέχθηκε από τη φυσική κίνηση |
| Προφίλ | Επαναχρησιμοποιήσιμο σύνολο ρυθμίσεων για μια λειτουργία |
| ROM | Εικόνα firmware που απαιτείται από μια μηχανή προσομοίωσης |
| Αποθηκευμένη κατάσταση | Ένα στιγμιότυπο μιας κατάστασης μηχανής εξομοιωτή που εκτελείται |
| Αποτύπωμα | Το σύστημα υποστήριξης γραφικών που χρησιμοποιείται για την εμφάνιση εξόδου εξομοίωσης |
